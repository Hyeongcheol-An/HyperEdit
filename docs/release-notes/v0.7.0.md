# HyperEdit v0.7.0 — release notes draft

> Hand-written body for the GitHub Release page. `CHANGELOG.md` is generated by semantic-release from the commits and is not edited by hand; this file is the human summary the maintainer can paste (or trim) into the release description.

## English

The interface now speaks eleven languages, and you can pick one inside the app.

### New

- **Interface language setting** — Settings (⌘,) › Language lists English, 한국어, 简体中文, 日本語, Tiếng Việt, हिन्दी, Deutsch, Français, Español, Português (Brasil) and العربية, each written in its own script, plus **System Default**, which shows the language the system setting would give you. Choosing one and clicking **Relaunch Now** saves the document, quits and reopens HyperEdit in that language. The choice is stored as the app's `AppleLanguages` preference — the same key System Settings › General › Language & Region › Applications uses — so the two never disagree. Regional variants map to the right translation (pt-PT and pt-BR → Portuguese, zh-CN → Simplified Chinese, de-CH → German); anything else falls back to English.
- **Nine new translations** of every menu, ribbon label, tooltip, settings field, status-bar and log message: Simplified Chinese, Japanese, Vietnamese, Hindi, German, French, Spanish, Portuguese and Arabic, alongside the existing English and Korean. Arabic text is right-to-left; the window layout (ribbon, sidebar, panels, editor) stays left-to-right as in most code editors, and the text you type follows its own direction. Ribbon labels were kept within the fixed button widths in every language.
- **User guide in eleven languages** — `docs/guide/USER_GUIDE.md` and ten translations cover installation, every feature, the settings, shortcuts, the files HyperEdit writes and troubleshooting. **Help › User Guide** and the **Open User Guide** button in Settings open the guide for the current interface language on GitHub; the README language bar links to all of them.
- **Welcome text in your language** — the default document created on first launch (`~/Documents/HyperEdit/notes.md`) is now written in the interface language instead of a fixed English/Korean mix. Existing files are never touched.

### For contributors

- Translations live in one flat JSON file per language, `l10n/ui.<code>.json`, with `l10n/context.json` describing where each string appears and its ribbon length limit. `scripts/l10n-export.py` adds new English keys to the catalogs and refreshes the files; `scripts/l10n-add.py --check` validates a file (placeholders, ribbon widths); `scripts/l10n-add.py` merges it. `scripts/check-l10n.py` (CI) now checks placeholder parity in every language, the ribbon label widths, and that the language list, user guides and welcome texts stay in sync.
- The self-test verifies that all eleven languages are present in both the app and the engine bundle and that the language setting round-trips; new unit tests cover the welcome-text loader.

### Known limitations

- Changing the language needs a relaunch (SwiftUI and AppKit choose the bundle language at launch); the Settings button does it for you.
- Languages outside the eleven (Traditional Chinese, for example) show English. Document text, file names and inserted dates are not translated — the timestamp weekday follows the system locale.
- Translations were produced with care but without native-speaker review for every language; corrections are welcome as pull requests to `l10n/ui.<code>.json` and `docs/guide/`.

## 한국어

인터페이스가 11개 언어를 지원하고, 앱 안에서 언어를 고를 수 있습니다.

### 새 기능

- **인터페이스 언어 설정** — 설정(⌘,) › 언어 에 English, 한국어, 简体中文, 日本語, Tiếng Việt, हिन्दी, Deutsch, Français, Español, Português (Brasil), العربية 가 각 언어의 문자로 나열되고, **시스템 기본값** 항목은 시스템 설정이 줄 언어를 함께 보여 줍니다. 언어를 고르고 **지금 재실행** 을 누르면 문서를 저장하고 종료한 뒤 그 언어로 다시 열립니다. 선택은 앱의 `AppleLanguages` 환경설정 — 시스템 설정 › 일반 › 언어 및 지역 › 응용 프로그램 이 쓰는 것과 같은 키 — 에 저장되므로 두 경로가 어긋나지 않습니다. 지역 변형은 맞는 번역으로 연결되고(pt-PT·pt-BR → 포르투갈어, zh-CN → 중국어 간체, de-CH → 독일어) 그 밖의 언어는 영어로 표시됩니다.
- **새 번역 9개** — 메뉴·리본 라벨·툴팁·설정 항목·상태바·로그 메시지 전부를 중국어 간체, 일본어, 베트남어, 힌디어, 독일어, 프랑스어, 스페인어, 포르투갈어, 아랍어로 번역했습니다(기존 영어·한국어 포함 11개). 아랍어는 오른쪽에서 왼쪽으로 쓰지만 창 배치(리본·사이드바·패널·편집기)는 다른 코드 편집기처럼 좌→우로 고정되고, 입력하는 텍스트는 제 방향을 따릅니다. 리본 라벨은 모든 언어에서 고정된 버튼 폭 안에 들어가도록 맞췄습니다.
- **11개 언어 사용자 가이드** — `docs/guide/USER_GUIDE.md` 와 번역 10개가 설치, 모든 기능, 설정, 단축키, HyperEdit 가 쓰는 파일, 문제 해결을 다룹니다. **도움말 › 사용자 가이드** 와 설정의 **사용자 가이드 열기** 버튼이 현재 인터페이스 언어의 가이드를 GitHub 에서 열고, README 의 언어 바가 전부를 연결합니다.
- **언어별 환영문** — 첫 실행 때 만들어지는 기본 문서(`~/Documents/HyperEdit/notes.md`)가 고정된 영/한 혼합문 대신 인터페이스 언어로 작성됩니다. 이미 있는 파일은 건드리지 않습니다.

### 기여자용

- 번역은 언어별 평면 JSON 하나(`l10n/ui.<code>.json`)에 있고, `l10n/context.json` 이 문자열마다 쓰이는 곳과 리본 길이 제한을 설명합니다. `scripts/l10n-export.py` 가 새 영어 키를 카탈로그에 넣고 파일을 갱신하며, `scripts/l10n-add.py --check` 가 파일을 검사(자리표시자·리본 폭)하고, `scripts/l10n-add.py` 가 병합합니다. `scripts/check-l10n.py`(CI)는 이제 모든 언어의 자리표시자 일치, 리본 라벨 폭, 언어 목록·가이드·환영문의 동기화를 검사합니다.
- 셀프테스트가 앱·엔진 번들에 11개 언어가 모두 들어 있는지와 언어 설정의 저장/복원을 확인하고, 환영문 로더에 단위 테스트가 추가됐습니다.

### 알려진 제한

- 언어 변경에는 재실행이 필요합니다(SwiftUI·AppKit 은 실행 시점에 번들 언어를 고릅니다). 설정의 버튼이 대신 해 줍니다.
- 11개 밖의 언어(예: 중국어 번체)는 영어로 표시됩니다. 문서 내용·파일 이름·삽입되는 날짜는 번역 대상이 아니며, 타임스탬프의 요일은 시스템 로케일을 따릅니다.
- 번역은 신중히 만들었지만 모든 언어를 원어민이 검토하지는 않았습니다. 수정은 `l10n/ui.<code>.json` 과 `docs/guide/` 에 풀 리퀘스트로 보내 주세요.
