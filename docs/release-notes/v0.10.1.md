## Release notes

A small correction to file tabs.

### Fixed

- **Tabs of deleted files** — closing the tab you are viewing moves to the nearest tab on its left whose file still exists. Tabs it passed over, whose files had been deleted, stayed in the tab bar until they were clicked; they are removed again, as in the description of the tab model.

### Compatibility

- macOS 15 (Sequoia) or later. The DMG (`HyperEdit-<version>-universal.dmg`) contains one universal binary that runs natively on Apple Silicon (arm64) and Intel (x86_64) Macs.
