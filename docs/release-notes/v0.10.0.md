## Release notes

File tabs: every open file now has its own tab above the editor, modelled on UltraEdit's file tabs.

### New

- **File tabs** — one tab per open file; click to switch, drag to reorder, and the tab's tooltip shows the full path, size and modification time. ⌘W, the ×, a double-click or a middle-click closes a tab (unsaved edits are saved first). Closing the tab you are viewing moves to the tab on its left; double-clicking a tab you are not viewing closes it and leaves you on the one you were reading. Double-click the empty tab bar for a new file. Right-click a tab for Close Other Tabs, Close Tabs to the Left / Right, Close All Tabs (⇧⌘W), Reopen Last Closed Tab (⇧⌘T), Save, Save and Close, Revert to Saved, Copy Path, Reveal in Finder and Sort Tabs (by name, path, extension or modification date). ⇧⌘] / ⇧⌘[ step through the tabs, ⌃Tab returns to the tab you viewed last, ⌃⇧Tab goes to the previous tab, and the ▾ at the right end lists all open tabs.
- **Each file keeps its place** — the caret, the scroll position (the same paragraph at the same height) and the folds of a file come back when you return to its tab. Folds are kept while the app runs; they are not saved for the next launch.
- **Tabs are restored on the next launch** — up to 30 (the most recently opened), with their contents read when you first switch to them. A tab whose file has been deleted is removed when you click it instead of creating an empty file. The research behind the model is in `docs/tabs-model.ko.md`.

### Fixed

- When a file changed on disk and was read again, the caret jumped to the end of the document; it now stays where it was.
- A find-in-files result whose file was deleted after the search no longer creates an empty file when clicked.

### For contributors

- Tabs are a list of file URLs (`AppModel.tabs`) over the single live `MemoDocument`: `open(url:)` appends a tab and switches with `document.switchTo(url:)`, `activateTab(_:)` / `closeTab(_:)` and friends manage the list. A first implementation with one `NSTextStorage` per tab, swapped into the shared `NSTextContentStorage`, was dropped — TextKit 2 layout degraded ("layout failed to converge") and the app crashed during a display pass. Self-tests close temporary tabs with `closeTabs(in:)` before deleting their folders. `MemoDocument.switchTo(url:)` now reports what happened to the file being left (`lastLeaveOutcome`: saved, kept on disk, rescued to an emergency copy, or failed — in which case it does not switch), and the `before-first-save` snapshot is taken once per file per run, also on the synchronous save path. Tab drags use a private type (`io.github.hyeongcheol-an.hyperedit.tab`) so a tab dropped on the editor does not insert its path.
- 22 new strings (19 menu items, 3 messages) are translated in all ten translations. Automated runs (`--ephemeral`, self-test, bench) now use a temporary default-document folder and bookmark store, so they cannot reach the real `notes.md`; the self-test now runs in the background (it gives focus back and keeps its window behind; `--selftest-foreground` restores the old behaviour), and its Quick Append panel no longer takes the keyboard or floats above other apps.

### Known limitations

- Leaving or closing a tab never asks: HyperEdit autosaves, so the file is written first. If it cannot be written (read-only folder, full disk, ejected volume), the unsaved text is written to an emergency copy in the snapshot folder and the Output panel says where; if that fails too, the tab stays open so nothing is lost. Only the active tab is held in memory — the undo history of a file is cleared when you switch away from it, and the unsaved-changes dot appears on the active tab only. Closing the last tab opens the default document instead of leaving the editor empty; when the only tab is the default document, ⌘W closes the window.
- A file can be open in one tab only; the split editor (⌘\\) shows the active document in both panes.
- Tabs cannot be dragged out into a new window, and there is no multi-row tab bar.

### Compatibility

- macOS 15 (Sequoia) or later. The DMG (`HyperEdit-<version>-universal.dmg`) contains one universal binary that runs natively on Apple Silicon (arm64) and Intel (x86_64) Macs.
- **⌘W behaves differently:** it now closes the current tab instead of the window (when the only tab is the default document it still closes the window; in Settings or the Quick Append panel it closes that window). Opening a file adds a tab instead of replacing the document in the window.
- New shortcuts: ⇧⌘W, ⇧⌘T, ⇧⌘], ⇧⌘[, ⌃Tab and ⌃⇧Tab.
- No settings or files need migrating. The list of open tabs is stored in the app's preferences (`ui.openDocuments`).
