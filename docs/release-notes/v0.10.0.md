## Release notes

File tabs: every open file now has its own tab above the editor, modelled on UltraEdit's file tabs.

### New

- **File tabs** — one tab per open file; click to switch, drag to reorder, and the tab's tooltip shows the full path, size and modification time. ⌘W, the ×, a double-click or a middle-click closes a tab (unsaved edits are saved first; closing the active tab moves to the tab on its left). Double-click the empty tab bar for a new file. Right-click a tab for Close Other Tabs, Close Tabs to the Left / Right, Close All Tabs (⌘⇧W), Reopen Last Closed Tab (⌘⇧T), Save, Save and Close, Revert to Saved, Copy Path, Reveal in Finder and Sort Tabs (by name, path, extension or modification date). ⌘⇧] / ⌘⇧[ step through the tabs, ⌃Tab returns to the tab you viewed last, ⌃⇧Tab goes to the previous tab, and the ▾ at the right end lists all open tabs. Open tabs are restored on the next launch (their contents are read when you first switch to them). The research behind the model is in `docs/tabs-model.ko.md`.

### For contributors

- Tabs are a list of file URLs (`AppModel.tabs`) over the single live `MemoDocument`: `open(url:)` appends a tab and switches with `document.switchTo(url:)`, `activateTab(_:)` / `closeTab(_:)` and friends manage the list. A first implementation with one `NSTextStorage` per tab, swapped into the shared `NSTextContentStorage`, was dropped — TextKit 2 layout degraded ("layout failed to converge") and the app crashed during a display pass. Self-tests close temporary tabs with `closeTabs(in:)` before deleting their folders.
- 19 new menu strings are translated in all ten languages.

### Known limitations

- Leaving or closing a tab never asks: HyperEdit autosaves, so the file is written first. Only the active tab is held in memory — the undo history of a file is cleared when you switch away from it, and the unsaved-changes dot appears on the active tab only. Closing the last tab opens the default document instead of leaving the editor empty; when the only tab is the default document, ⌘W closes the window.
- A file can be open in one tab only; the split editor (⌘\\) shows the active document in both panes.
- Tabs cannot be dragged out into a new window, and there is no multi-row tab bar.

### Compatibility

- macOS 15 (Sequoia) or later. The DMG (`HyperEdit-<version>-universal.dmg`) contains one universal binary that runs natively on Apple Silicon (arm64) and Intel (x86_64) Macs.
- No settings or files need migrating. The list of open tabs is stored in the app's preferences (`ui.openDocuments`).
