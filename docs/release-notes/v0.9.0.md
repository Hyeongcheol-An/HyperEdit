## Release notes

Find works like UltraEdit's Quick Find: results appear as you type, Enter steps through them, and the find field no longer slows down on large files.

### New

- **Quick Find** — as you type in the Find bar (⌘F), the first match after the caret is selected and every match is highlighted in the editor and listed with line numbers, 150 ms after the last keystroke. Enter jumps to the next match and ⇧Enter to the previous one while the field keeps focus; Esc closes the panel and clears the highlights (the selection stays). F3 / ⇧F3 keep stepping from the caret and re-run the search first when the field holds a new query. On files over about 64 MB (64 million characters) the search waits for Enter. The inferred UltraEdit model and its sources are in `docs/find-model.ko.md`.

### Performance

- **Typing in the Find bar** — the find, replace and file-mask fields are no longer bound to the app model, so a keystroke re-draws only the field instead of the whole window: on a 28 MB log with 10,000 results open and a large folder in the file view, 20–27 ms per keystroke became 2.5 ms.

### For contributors

- `scripts/bench.sh --only findquery` measures typing in the find field with a 9,200-entry folder tree in the file view; `find.e2e.*` (Enter → results drawn) is now the strict find budget and `find.publish` / `find.frame` are informational.
- `FindFields` holds the three text fields; `AppModel.commitFindFields()` moves them into `searchQuery`, `replaceText` and `fileMask` on user actions. `AppModel.hitsQuery` says which query the current results belong to; `EditorCommand.selectMatch` selects without taking focus.

### Known limitations

- Results are capped at 10,000 matches. Past the last listed match, Enter / F3 wrap to the first one even if the file has more matches further down.
- The Aa / W / .* toggles also apply to the as-you-type search (UltraEdit's Quick Find ignores them). Matches inside masked secret blocks are skipped by the as-you-type selection; Enter / F3 still go there.

### Compatibility

- macOS 15 (Sequoia) or later. The DMG (`HyperEdit-<version>-universal.dmg`) contains one universal binary that runs natively on Apple Silicon (arm64) and Intel (x86_64) Macs.
- No settings or files need migrating. The Find bar behaves differently: the search now runs as you type and selects the first match after the caret (a selection you had is replaced and the editor scrolls to it); Enter steps to the next match instead of starting the search, ⇧Enter to the previous one; Esc hides the bottom panel and clears the highlights; the Aa / W / .* toggles also apply to the as-you-type search. Press Esc or ⌘2 to hide the panel.
