## Release notes

Secret blocks, HTML / PDF export, multi-line syntax colors with user-defined grammars, caret styles and window opacity, and an app lock.

### New

- **Secret blocks** — a fenced code block whose info string starts with `secret` (```` ```secret bank ````) is masked in the editor as a blank bar with `••••••••`; the fence lines stay visible. Put the caret inside to reveal and edit the block, move out to mask it again. **Reveal Secrets (⌥⌘S)** shows everything and re-masks after 10 / 30 / 60 s (default 30 s) or never. Find results, Find in Files, bookmark previews, the Markdown preview and exports show secret lines as `••••••••`; the Outline and Timeline skip them. Copying text that overlaps a secret line clears the clipboard after 30 s (configurable), and **Edit › Clear Clipboard** clears it at once. This is masking, not encryption: the file and its snapshots stay plain text.
- **Export as HTML / PDF** (File menu) — Markdown is rendered like the preview, notes and code become a syntax-colored block; the HTML is self-contained with no scripts, and the PDF is paginated (Letter or A4 by region, 36 pt margins). The save panel offers the theme and, for notes and code, line numbers.
- **Syntax colors across lines** — block comments, multi-line strings (Swift / Python `"""`, JavaScript template literals, Go raw strings, Rust `r#"…"#`) and Markdown fenced code blocks keep their color until they close, and fences are colored with the language named in the info string. A per-line state table computes a 34k-line file in about 10 ms and updates only the edited lines, so typing stays at about 2 ms per keystroke.
- **User-defined grammars** — `~/Library/Application Support/HyperEdit/grammars/*.json` adds a language or overrides a built-in one with its name, extensions or file names, comment markers, string delimiters and keyword lists. HyperEdit creates the folder on first launch with an `example.json` and a schema README; **File › Open Grammars Folder…** opens it and **File › Reload Grammars** applies changes without restarting. Toggle Comment (⌘/) follows the grammar.
- **App lock (Touch ID)** — **HyperEdit › Lock HyperEdit (⌃⌘L)** covers the whole window with an opaque lock screen and hides even the file name; **Unlock** authenticates with Touch ID or your login password. Settings › App Lock can require authentication at launch, lock after 1–30 minutes without input, and lock when the Mac sleeps or the screen locks. While locked, typing and menus are blocked, open sheets are closed, revealed secrets are masked again and the Quick Append shortcut asks you to unlock first. It hides the screen (also from VoiceOver); it does not encrypt files.
- **Cursor style and window opacity** (Settings › Appearance) — Bar, Block or Underline caret with blinking on or off, applied to multi-caret and column-mode carets as well; window opacity 50–100 % with an optional blur behind the window, also from View › Window Opacity.

### For contributors

- New developer flags: `--cursor <bar|block|underline>`, `--no-cursor-blink`, `--opacity <0.5–1.0>`, `--blur`, `--reveal-secrets`, `--locked`. The DMG is now named `HyperEdit-<version>-universal.dmg` and release notes are written in English.
- Under TextKit 2, `NSTextView.drawInsertionPoint` is never called (the system insertion indicator draws the caret); the secondary carets of multi-caret and column mode are now drawn from `drawBackground`, which also fixes them not appearing in v0.7.

### Known limitations

- Secret blocks hide text on screen only; the file, autosaves, snapshots and Find in Files results from other files are plain text, and the mask bar shows each line's length.
- Export writes the whole document; there is no selection or multi-file export, no page-size or font options and no PDF table of contents. PDF export is limited to 2 MB.
- Apart from Rust raw strings, multi-line strings must use the same opening and closing delimiter; one block-comment pair per language; user grammars are word lists without regular-expression rules.
- App lock is a screen lock, not encryption; a sheet that was open when you locked stays above the lock screen, and the idle timer only sees input made in HyperEdit.
- Inside a single paragraph longer than 20,000 characters the Block and Underline carets fall back to the bar caret; secondary carets do not blink.
- A secret fence must start at the left margin (not inside a list item or quote); block comments do not nest; exported HTML keeps image URLs as written, so remote images may be fetched.

### Compatibility

- macOS 15 (Sequoia) or later. The DMG (`HyperEdit-<version>-universal.dmg`) contains one universal binary that runs natively on Apple Silicon (arm64) and Intel (x86_64) Macs.
- No settings or files need migrating. New settings default to the previous behaviour (bar caret, opaque window, masking on, app lock off).
