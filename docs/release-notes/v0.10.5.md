## Release notes

The Files sidebar no longer stalls the window in large folders.

### Performance

- **Switching tabs between folders** — with the Files sidebar open, switching between a file in a folder of 5,300 entries and a file elsewhere took 1.6–3.4 s per switch; it now takes 60–90 ms. Toggling the bottom panel while such a folder was shown took 1.5 s and now takes about 40 ms.
- Folders are read one level at a time off the main thread, sub-folders when they are expanded, and each folder you have visited keeps its list, expansion and scroll position.

### Fixed

- Folders nested more than three levels deep showed as empty.
- A file created in the folder that the sidebar already shows appears in the list when it is opened.
- A row whose file has been deleted no longer creates an empty file when clicked.

### For contributors

- The list is an `NSOutlineView` (`Panels/FileOutlineView.swift`) instead of a SwiftUI `List` with `OutlineGroup`; 7 `fileview-*` real-use scenarios compare the rows with the disk after every step.

### Compatibility

- macOS 15 (Sequoia) or later. The DMG (`HyperEdit-<version>-universal.dmg`) contains one universal binary that runs natively on Apple Silicon (arm64) and Intel (x86_64) Macs.
