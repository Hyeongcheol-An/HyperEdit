# HyperEdit v0.6.0 — release notes draft

> Hand-written body for the GitHub Release page. `CHANGELOG.md` is generated by semantic-release from the commits and is not edited by hand; this file is the human summary the maintainer can paste (or trim) into the release description. Numbers come from [docs/performance.md](../performance.md) and the self-test; see the caveats there.

## English

Eight editing features, a performance pass with a benchmark harness, and a smaller binary. Everything below works on macOS 15 or later; no settings or files need migrating.

### New

- **Toggle Comment (⌘/)** — comments or uncomments the selected lines (or the current line) with the file type's marker: `//`, `#`, `--`, … for code, `<!-- -->` for Markdown and HTML/XML, `/* */` for CSS, `//` for plain notes. VS Code semantics: all commented → all uncommented, otherwise all commented, markers aligned at the shallowest indentation.
- **Format JSON (⌃⌘J) / Minify JSON** — pretty-prints (2-space) or collapses the selection or the whole document. Key order and number text are preserved, Korean and emoji stay unescaped, JSONC input (comments, trailing commas, BOM) is accepted, and a syntax error reports `line:column` in the Output panel and moves the caret there. 5.6 MB in about 30 ms.
- **Snippets** — type a trigger (`todo`, `date`, `time`, `now`, `meeting`, `table`, `link`, `code`) and press Tab, or pick from **Insert Snippet… (⇧⌘I)**. Variables `${date}` `${time}` `${datetime}` `${selection}` `${clipboard}` `${filename}`, tabstops `$1`…`$9`, `${1:placeholder}` and `$0` with Tab / ⇧Tab navigation. **Edit Snippets…** opens `~/Library/Application Support/HyperEdit/snippets.json` in HyperEdit.
- **Macros (⇧⌘M record / stop, ⌥⌘M play)** — records typing (committed syllables for Korean IME), caret and deletion commands, paste, the text tools and Find Next (F3), then replays at the caret. **Play Macro Multiple Times…** repeats up to 10,000× and stops when a Find step fails or a run changes nothing; a whole run is one undo step. **Save Last Macro As…** adds it to the Macro menu (`~/Library/Application Support/HyperEdit/macros/macros.json`). Status bar shows `● REC` while recording.
- **Split editor (⌘\\, ⌥⌘\\ to focus the other split)** — the same document in two editors, side by side or stacked. Both share the text and one undo stack (type in one, ⌘Z in the other) and scroll independently; commands and the status bar follow the editor you used last. Status bar shows **SPLIT**.
- **Quick Append (⇧⌘N, global ⌃⌥N)** — a floating panel that does not activate HyperEdit. Type a note, press ⌘↩ and it is appended to the end of the document with a timestamp heading, saved at once and undoable in one step; focus returns to the app you were in. The global shortcut (off / ⌃⌥N / ⌃⌥Space / ⌃⇧Space / ⌃⌥⌘N) is set in Settings and needs no Accessibility permission.
- **Code folding (⌥⌘← / ⌥⌘→, all regions ⌥⇧⌘← / ⌥⇧⌘→)** — folds indented blocks, Markdown headings (through the next heading of the same or higher level, fenced code too) and `{ [ (` blocks in code. Gutter chevrons and a `⋯ N lines` pill toggle with the mouse; moving the caret into a fold (find, go to line, bookmarks, undo) unfolds it; ↑ / ↓ skip folds; folds follow edits.
- **Scrollbar markers** — a strip at the editor's right edge shows search matches, bookmarks, the caret line and folded headers at their relative positions (View › Scrollbar Markers, or the Layout tab).

### Performance

A benchmark harness (`scripts/bench.sh`, `--bench`) now measures typing, file open, search, replace, scrolling, theme switch, memory, idle CPU and cold launch against fixed budgets on a generated 2 KB–8 MB corpus; the budgets and baseline are in `docs/performance.md`. What it found and what changed in this release: the single ⌘Z after a 5,000-match Replace All went from about 1.7 s to 0.25 s (one batched undo instead of AppKit replaying every range); per-keystroke SwiftUI re-evaluation of the search, outline and timeline panels and a redundant `isDirty` publish were removed, so typing in the middle of a 1.3 MB / 8 MB file measures about 3 ms median (p95 ≈ 6 ms) and at the end about 1.2 ms; the installed-font list is cached instead of being queried three times per theme change (~60 ms off launch and file open); the syntax highlighter no longer allocates a buffer per laid-out line. Release builds now strip symbols and dead code, taking the universal binary from 13.5 MB to 6.5 MB. The published baseline was recorded while other builds were running on the machine and is marked provisional; the undo and typing improvements were measured back-to-back on the same load.

### Also

- Document dirty state, autosave and line-index updates are now driven by text-storage notifications, so undo and redo that bypass the text view (TextKit 2 on macOS 27) are tracked correctly.
- Manual testing can use `--ephemeral` (throwaway preferences, remembered file, snippets and macros). New developer flags: `--split`, `--quick-append`, `--snapshot-panel`, `--fold`, `--fold-all`, `--no-fold`, `--bench*`, `--quit-after-launch`.
- 137 unit tests and a 155-check self-test (`--selftest`), both passing.

### Known limitations

- Macros record keyboard editing only — no mouse clicks, selection changes or multi-caret edits (Replace All, Insert Number).
- Folding lasts for the session (not saved per file), and a mouse drag across a folded header still selects the hidden text.
- Toggle Comment is line-based (no block-comment selection); the JSON formatter has no sort or schema features; JSON parser error messages are English only.
- Snippets and macros are edited as JSON files; there is no GUI editor.
- The ⌃Space and ⌃⌥Space global-shortcut variants are usually taken by input-source switching in System Settings › Keyboard, in which case macOS wins silently — use ⌃⌥N or ⌃⌥⌘N.

Install: `brew tap Hyeongcheol-An/tap && brew install --cask hyperedit`, or download the signed and notarized DMG below and verify with `shasum -a 256 -c SHA256SUMS`.

## 한국어

편집 기능 8개, 벤치마크 하네스를 동반한 성능 개선, 더 작아진 바이너리. macOS 15 이상에서 동작하며 설정이나 파일을 옮길 필요는 없습니다.

### 새 기능

- **주석 토글(⌘/)** — 선택한 줄(없으면 현재 줄)에 파일 종류의 주석 기호를 넣거나 뺍니다: 코드는 `//`, `#`, `--` 등, 마크다운·HTML/XML 은 `<!-- -->`, CSS 는 `/* */`, 일반 메모는 `//`. VS Code 방식으로 전부 주석이면 모두 해제, 아니면 모두 주석 처리하며 기호는 가장 얕은 들여쓰기에 맞춥니다.
- **JSON 정리(⌃⌘J) / JSON 한 줄로** — 선택 영역(없으면 문서 전체)을 들여쓰기 2칸으로 정리하거나 한 줄로 줄입니다. 키 순서와 숫자 표기를 유지하고 한글·이모지는 그대로 두며, 주석·뒤따르는 쉼표·BOM 이 있는 JSONC 도 받습니다. 문법 오류는 출력 패널에 `줄:열` 로 알리고 캐럿을 그 자리로 옮깁니다. 5.6 MB 를 약 30 ms 에.
- **스니펫** — 트리거(`todo`, `date`, `time`, `now`, `meeting`, `table`, `link`, `code`)를 치고 Tab, 또는 **스니펫 삽입…(⇧⌘I)** 에서 고릅니다. 변수 `${date}` `${time}` `${datetime}` `${selection}` `${clipboard}` `${filename}`, 탭스톱 `$1`…`$9`·`${1:자리표시자}`·`$0` 을 Tab / ⇧Tab 으로 이동. **스니펫 편집…** 은 `~/Library/Application Support/HyperEdit/snippets.json` 을 HyperEdit 로 엽니다.
- **매크로(⇧⌘M 기록/중지, ⌥⌘M 재생)** — 타이핑(한글 IME 는 확정 글자만), 캐럿·삭제 명령, 붙여넣기, 텍스트 도구, 다음 찾기(F3)를 기록해 캐럿 위치에서 재생합니다. **매크로 여러 번 재생…** 은 최대 10,000회 반복하며 찾기 실패나 무변화 시 멈추고, 전체 재생은 실행 취소 한 단계입니다. **마지막 매크로 이름 붙여 저장…** 으로 매크로 메뉴에 등록(`~/Library/Application Support/HyperEdit/macros/macros.json`). 기록 중에는 상태바에 `● REC`.
- **편집기 분할(⌘\\, ⌥⌘\\ 로 다른 분할에 포커스)** — 같은 문서를 두 편집기로 좌우 또는 상하로 봅니다. 텍스트와 undo 스택을 공유하고(한쪽에서 입력, 다른 쪽에서 ⌘Z) 스크롤은 따로 하며, 명령과 상태바는 마지막으로 쓴 편집기를 따릅니다. 상태바에 **SPLIT**.
- **빠른 추가(⇧⌘N, 전역 ⌃⌥N)** — HyperEdit 를 활성화하지 않는 떠 있는 창입니다. 메모를 쓰고 ⌘↩ 를 누르면 타임스탬프 헤딩과 함께 문서 끝에 붙고 바로 저장되며 undo 한 번으로 되돌릴 수 있고, 포커스는 쓰던 앱으로 돌아갑니다. 전역 단축키(끔 / ⌃⌥N / ⌃⌥Space / ⌃⇧Space / ⌃⌥⌘N)는 설정에서 고르며 손쉬운 사용 권한이 필요 없습니다.
- **접기(⌥⌘← / ⌥⌘→, 모두 ⌥⇧⌘← / ⌥⇧⌘→)** — 들여쓴 블록, 마크다운 헤딩(같거나 높은 레벨의 다음 헤딩까지, 펜스 코드 블록 포함), 코드의 `{ [ (` 블록을 접습니다. 거터 화살표와 `⋯ N lines` 표식으로 마우스 토글, 캐럿이 접힌 줄로 들어가면(찾기·줄 이동·북마크·undo) 자동으로 펼치고 ↑ / ↓ 는 접힌 구간을 건너뛰며 접힘은 편집을 따라갑니다.
- **스크롤바 마커** — 편집기 오른쪽 가장자리 띠에 검색 매치·북마크·캐럿 줄·접힌 머리 줄을 상대 위치로 표시합니다(보기 › 스크롤바 마커, 레이아웃 탭).

### 성능

벤치마크 하네스(`scripts/bench.sh`, `--bench`)가 2 KB~8 MB 생성 말뭉치에서 타이핑·열기·검색·바꾸기·스크롤·테마 전환·메모리·유휴 CPU·콜드 실행을 고정 예산과 비교합니다(예산과 기준선은 `docs/performance.md`). 이번 릴리스에서 고친 것: 5,000건 모두 바꾸기 뒤 ⌘Z 한 번이 약 1.7 s 에서 0.25 s 로(AppKit 이 범위마다 되돌리던 것을 일괄 undo 하나로); 검색·아웃라인·타임라인 패널의 키 입력마다 일어나던 SwiftUI 재평가와 중복 `isDirty` 발행을 제거해 1.3 MB / 8 MB 파일 중간 타이핑이 중앙값 약 3 ms(p95 약 6 ms), 끝에서는 약 1.2 ms; 설치 폰트 목록을 테마 적용마다 세 번 묻던 것을 캐시(실행·파일 열기에서 약 60 ms 절감); 하이라이터의 줄마다 버퍼 할당 제거. Release 빌드는 심볼과 미사용 코드를 제거해 유니버설 바이너리가 13.5 MB 에서 6.5 MB 로 줄었습니다. 공개된 기준선은 다른 빌드가 도는 머신에서 측정해 잠정값으로 표시했고, undo·타이핑 개선치는 같은 부하에서 연속 측정한 값입니다.

### 그 밖에

- 문서의 수정 상태·자동 저장·줄 인덱스 갱신이 텍스트 스토리지 알림을 따르므로, 텍스트 뷰를 거치지 않는 undo/redo(macOS 27 의 TextKit 2)도 정확히 추적됩니다.
- 수동 테스트는 `--ephemeral`(휘발성 설정·마지막 파일·스니펫·매크로)로. 새 개발용 인자: `--split`, `--quick-append`, `--snapshot-panel`, `--fold`, `--fold-all`, `--no-fold`, `--bench*`, `--quit-after-launch`.
- 단위 테스트 137개, 셀프테스트 155개 검사(`--selftest`) 모두 통과.

### 알려진 제한

- 매크로는 키보드 편집만 기록합니다 — 마우스 클릭, 선택 변경, 멀티 커서 편집(모두 바꾸기·숫자 채우기)은 기록되지 않습니다.
- 접기는 세션 동안만 유지되고(파일별 저장 없음), 접힌 머리 줄을 지나는 마우스 드래그 선택에는 숨은 텍스트가 포함됩니다.
- 주석 토글은 줄 단위(블록 주석 선택 없음), JSON 정리에는 정렬·스키마 기능이 없고 파서 오류 메시지는 영어입니다.
- 스니펫과 매크로는 JSON 파일로 편집합니다. GUI 편집기는 없습니다.
- 전역 단축키의 ⌃Space·⌃⌥Space 변형은 시스템 설정 › 키보드의 입력 소스 전환이 먼저 가로채며 아무 알림이 없습니다 — ⌃⌥N 이나 ⌃⌥⌘N 을 쓰세요.
