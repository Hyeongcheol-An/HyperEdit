## 1. インストールとアップデート

**動作環境:** macOS 15 (Sequoia) 以降。アプリはユニバーサルバイナリ (Apple シリコンと Intel) で、署名と公証が済んでいるため、Gatekeeper の警告なしに開けます。

**Homebrew**

```sh
brew tap Hyeongcheol-An/tap
brew install --cask hyperedit
```

その後のアップデートは `brew upgrade --cask hyperedit` で行います。Homebrew 7 では、先に tap を信頼するよう求められることがあります: `brew trust Hyeongcheol-An/tap`。

**DMG:** [GitHub Releases](https://github.com/Hyeongcheol-An/HyperEdit/releases) から `HyperEdit-x.y.z-universal.dmg` をダウンロードして開き、`HyperEdit.app` を `Applications` にドラッグします。ダウンロードを検証するには、`SHA256SUMS` を DMG の隣に置いて `shasum -a 256 -c SHA256SUMS` を実行します。

HyperEdit にはネットワークコードもテレメトリもありません。外部に通信することは一切なく、アップデートはアプリが勝手に行うものではなく、あなたが行うものです。

## 2. 初回起動

HyperEdit は `~/Documents/HyperEdit/notes.md` を開きます。このファイルがなければ、あなたの言語の短い歓迎文とともに作成されます — その文章を消して書き始めてください。1 つのファイルを持ち続けて追記していくという考え方ですが、それが強制されるわけではありません:

- **⌘N** で新しい空のテキストファイルを作成します (名前とフォルダを選びます)。
- **⌘O** で他のテキストファイルを開きます。最後に開いたファイルは次回の起動時に記憶されています。
- **ファイル › デフォルト書類を開く** で `notes.md` に戻ります。
- バイナリファイル (画像、PDF、アーカイブなど) がエディタに読み込まれることはありません。代わりにデフォルトのアプリで開きます。

カーソルとスクロール位置はファイルごとに記憶されるので、30,000 行のファイルを開き直しても前回の場所に戻ります。**⌃⌘E** で書類の末尾へジャンプします — メモファイルでいちばんよく行きたい場所です。

## 3. インターフェイスの言語

インターフェイスは 11 の言語で利用できます: English (英語)、한국어 (韓国語)、简体中文 (簡体字中国語)、日本語、Tiếng Việt (ベトナム語)、हिन्दी (ヒンディー語)、Deutsch (ドイツ語)、Français (フランス語)、Español (スペイン語)、Português (ポルトガル語、ブラジル表記)、العربية (アラビア語) です。アラビア語のテキストは右から左に書かれますが、ウインドウのレイアウト — リボン、サイドバー、パネル、エディタ — は多くのコードエディタと同じく左から右のままです。入力するテキストはそれ自身の書字方向に従います。

デフォルトでは HyperEdit はシステムの言語に従います。別の言語を選ぶには:

1. **設定 (⌘,)** を開き、いちばん上の **言語** セクションを見ます。
2. **インターフェイスの言語** メニューから言語を選びます。各言語はその言語自身の文字で表示されるので、現在の言語が読めなくても自分の言語を見つけられます。**システムのデフォルト** には、システム設定が与える言語が表示されます。
3. **今すぐ再起動** をクリックします。書類が先に保存され、HyperEdit が終了して新しい言語で開き直します。(作業を続けてあとで再起動してもかまいません。選択はすでに保存されています。)

この選択は **システム設定 › 一般 › 言語と地域 › アプリケーション** と同じ場所に保存されるので、両者は常に一致します。**ヘルプ › ユーザガイド** と、設定の **ユーザガイドを開く** ボタンは、現在のインターフェイス言語でこのガイドを開きます。

リストにない言語は英語にフォールバックします (たとえば繁体字中国語)。書類のテキスト、ファイル名、挿入する日付はインターフェイスの言語の影響を受けません — タイムスタンプの曜日はシステムのロケールに従います。

## 4. ウインドウ

レイアウトは古典的なリボン型エディタにならっており、タイトルバーは隠れています。

- **リボンタブ** — **ホーム** (クリップボード、検索、挿入、モード、ファイル)、**編集** (行、大文字/小文字、並べ替え、空白、列・マルチカーソル、ツール、マクロ)、**レイアウト** (テーマ、パネル、折りたたみ、Markdown、文字サイズ)、**詳細** (設定、スナップショットフォルダ、再読み込み、デフォルト書類)、**ウインドウ** (フルスクリーン、パネル)。ウインドウが狭いときはグループが右側からアイコンに折りたたまれ、アイコンのツールチップにラベルが表示されます。
- **書類タブバー** — 現在のファイル名と、新規 (⌘N)・開く (⌘O) ボタン、さらにクイックアクセスの保存 / 取り消す / やり直す。
- **サイドバー (⌘1)** — **ファイル** (現在のファイルがあるフォルダ。1 クリックでファイルを開きます)、**アウトライン (⌘3)** (見出し、`[タイトル]` 行、番号付き項目。絞り込みボックス付きで、現在の項目がハイライトされます)、**タイムライン (⌘4)** (タイムスタンプ見出しを月ごとにまとめ、新しい順に表示)。
- **下部パネル (⌘2)** — **検索結果**、**ブックマーク**、そしてアプリが行ったこと (保存、置換、エラー) のログである **出力**。
- **ステータスバー** — 行と列 (選択中はその長さも。ホバーすると文字オフセットを表示)、改行コード (UNIX / DOS / MAC)、ファイルのエンコーディング、列モード中の **COL**、カーソル数、行数 · ファイルサイズ、最新のステータスメッセージ、構文の言語 (構文の色分けがオフのときは薄く表示)、テーマメニュー (システムの外観に従っている間は「· システム」付き)、ズーム率。ほとんどの項目はクリックできます。

## 5. 編集の基本

- 数 MB のファイルでも入力は軽快です。レイアウトされるのは書類の表示されている部分だけです。
- **折り返し** ⌥Z · **行番号** ⌥⌘L · **ズーム** ⌘= / ⌘- / ⌘0 (レイアウトタブにもあります)。
- **行へ移動** ⌘L · **書類の末尾** ⌃⌘E。
- **日付/時刻を挿入** F7 は `## 2026-10-31 (金) 14:05` のようなタイムスタンプ見出しを挿入します。曜日はシステムのロケールに従います。このような行がタイムラインの元になります。
- 現在の行はハイライトされ、ガターにはその行番号がテキストの色で表示されます。
- 取り消すとやり直すはセッション内で無制限で、以下のどのツールも 1 回の取り消し単位です。

## 6. 検索と置換

- **検索 (⌘F)** で検索バーが開きます。語句を入力して Enter を押すと、すべての一致が行番号とともに下部パネルに一覧表示され、一覧が開いている間はエディタ内の一致がハイライトされます。オプション: 正規表現 `.*`、大文字/小文字を区別 `Aa`、単語単位 `W`。**F3 / ⇧F3** で次 / 前の一致へ移動します。編集すると約 1 秒後に一覧が自動的に更新されます。
- **置換 (⌘R)** で置換フィールドが追加されます。現在の一致を置換して次へ進むか、**すべて置換** します。正規表現がオンのときは `$1` などのテンプレートでキャプチャグループを挿入できます。すべて置換は、一致が数千件あっても 1 回の取り消し単位です。
- **ファイルから検索 (⇧⌘F)** はフォルダ (サブフォルダを含む) を検索します。フォルダを選び、必要なら `*.md;*.txt` のようなマスクで絞り込み、ヒットをクリックするとそのファイルのその行が開きます。隠しファイル、パッケージ、バイナリファイル、20 MB を超えるファイルはスキップされます。
- **すべての一致を選択 (⌥⌘A)** はすべての一致をカーソルにします — 下のマルチカーソルを参照してください。

## 7. ブックマーク

**⌘F2** で現在の行をブックマークします (またはブックマークを外します)。**F2 / ⌥F2** で次 / 前のブックマークへジャンプし、下部パネルの **ブックマーク** タブにすべてが一覧表示されます。そこでブックマークに名前を付けることもできます。ブックマークは編集に合わせて行に追従します。上の行を挿入・削除すれば移動し、ブックマークした行を削除すれば消え、取り消せば戻ります。ブックマークは書類ごとに `~/Library/Application Support/HyperEdit/bookmarks/` に保存されるので、あなたのファイルの隣に何かが書き込まれることはありません。

## 8. 列モードとマルチカーソル

- **列モード (⌥C)** — ⌥ を押しながらドラッグするか、⇧ と矢印キーで矩形を選択します。入力と削除はブロックのすべての行に適用され、短い行は仮想スペースで埋められ、コピー / ペーストは行単位で動作します。ステータスバーには **COL** が表示されます。もう一度 ⌥C でオフになります。
- **連番を挿入 (⌥⌘N)** — 列選択 (またはすべてのカーソル) に連番を入れます。開始値と増分を指定でき、数字は同じ桁数になるよう 0 で埋められます。
- **マルチカーソル** — ⌘クリックでカーソルを追加、**⌘D** で選択テキスト (またはカーソル位置の単語) の次の出現箇所を追加、**⌥⌘A** ですべての検索一致を選択します。入力はすべてのカーソルに反映され、Esc で 1 つに戻ります。マルチカーソルでの編集はすべて 1 回の取り消し単位です。

## 9. 行とテキストのツール

これらは **編集** リボンタブと **行** メニューにあります。選択した行、または何も選択していなければ現在の行に作用します。

| グループ | ツール |
|---|---|
| 行 | 行を削除 ⇧⌘K · 行を複製 ⇧⌘D · 行を上へ / 下へ移動 ⌥↑ / ⌥↓ · 行を結合 ⇧⌘J · 行を逆順に · 行に番号を付ける |
| 大文字/小文字 | 大文字にする · 小文字にする · 語頭を大文字に · 大小文字を反転 |
| 並べ替え | 昇順 · 降順 · 数値順に並べ替え (各行の先頭の数値で) · 重複行を削除 |
| 空白 | 末尾の空白を削除 · 前後の空白を削除 · 空行を削除 · タブ → スペース · スペース → タブ |

- **計算 (⌃⌘=)** は選択範囲、または現在の行 (最後の `=` があればその後ろの部分) を評価し、` ⇒ 結果` を追加します: `3+0.5+0.25` は `3+0.5+0.25 ⇒ 3.75` になります。編集した行でもう一度実行すると古い結果が置き換えられます。対応: `+ - * / % ^`、括弧、`1,234` や `1_000` 形式の数、`sqrt abs round floor ceil min max`、`pi` と `e`。評価できない式は出力パネルに報告され、テキストはそのまま残ります。
- **列を揃える (⌃⌘T)** はタブ区切りの列 (選択した行、またはカーソル周辺のタブを含む行のブロック) を空白で埋め、各列が同じ表示桁から始まるようにします。韓国語・中国語・日本語の文字は 2 セルとして数えます。すべての行に `|` が含まれていれば、ブロックは代わりに Markdown の表として扱われます。セルは ` | ` の内側で埋められ、`---` の行は引き直され、`--:` の列は右揃えになります。
- **コメント切替 (⌘/)** はファイル種別の記号で行をコメント化またはコメント解除します: コードでは `//`、`#`、`--` など、Markdown と HTML では `<!-- -->`、CSS では `/* */`、プレーンなメモでは `//`。空でない行がすべてコメント済みならすべて解除し、そうでなければすべてコメント化します。記号はいちばん浅いインデントに揃えられ、空行はスキップされます。
- **JSON を整形 (⌃⌘J) / JSON を1行に** は選択範囲、または何も選択していなければ書類全体を整形 (2 スペースのインデント) または 1 行にまとめます。キーの順序と数値の表記は保持され、非 ASCII 文字はエスケープされず、入力にはコメントや末尾のカンマ (JSONC) を含めることができます。構文エラーがあるとテキストはそのまま残り、出力パネルに `行:列` が表示されてカーソルがそこへジャンプします。

## 10. スニペット

トリガーとなる単語を入力して **Tab** を押すと展開されます。組み込みのトリガー: `todo`、`date`、`time`、`now`、`meeting`、`table`、`link`、`code`。**スニペットを挿入… (⇧⌘I)** で絞り込みボックス付きの一覧が開き、ホームタブには「スニペット…」ボタンがあります。

スニペットの本文には変数 — `${date}`、`${time}`、`${datetime}`、`${selection}`、`${clipboard}`、`${filename}` — と、タブストップ `$1` … `$9`、`${1:placeholder}`、`$0` を含めることができます。展開後は Tab / ⇧Tab でタブストップ間を移動し (同じ番号を 2 回使うとマルチカーソルになります)、Esc またはクリックでセッションが終わります。

**スニペットを編集…** (編集メニューまたはホームタブ) は `~/Library/Application Support/HyperEdit/snippets.json` を HyperEdit 自身で開きます。各エントリには `trigger`、`name`、`body` があり、保存するとファイルが読み直されるので、新しいトリガーはすぐに使えます。

## 11. マクロ

マクロは入力した操作を記録し、別の場所で再生します。

1. **マクロを記録 (⇧⌘M)** で記録を開始します。ステータスバーには `● REC` が表示されます。記録されるのは、入力 (日本語などの IME では確定した文字)、カーソル移動、削除、改行、ペースト、テキストツール、次を検索 (F3、検索語句を含む) です。マウスクリック、選択範囲の変更、マルチカーソルでの編集は記録されません。
2. もう一度 **⇧⌘M** で記録を停止します。
3. **マクロを再生 (⌥⌘M)** でカーソル位置に再生します。**マクロを複数回再生…** は最大 10,000 回まで繰り返し、検索ステップが何も見つけないか、1 回の実行で何も変わらなければ自動的に停止します — 「これをすべての行に対して行う」ための便利なツールです。1 回の実行全体が 1 回の取り消し単位です。

最後の記録は終了するまでメモリ上にだけ保持されるので、記録中に入力した機密情報がディスクに書かれることはありません。**最後のマクロに名前を付けて保存…** で **マクロ** メニューに恒久的に追加されます。保存したマクロは `~/Library/Application Support/HyperEdit/macros/macros.json` にあり、**マクロファイルを編集…** でエディタに開けます。

## 12. コードの折りたたみとスクロールバーマーカー

**折りたたむ (⌥⌘←) / 展開 (⌥⌘→)** はカーソル位置の領域を隠したり表示したりします。**⌥⇧⌘← / ⌥⇧⌘→** はすべてを折りたたむ / 展開します。領域とは:

- 現在の行の下にインデントされた行 (空行は無視)、
- Markdown では、`#` 見出しの下にある、同じかそれより上位の次の見出しまでのすべて (フェンス付きコードブロックも折りたためます)、
- コードでは、`{`、`[`、`(` で終わる行から、対応する閉じ括弧の行まで。

ガターのシェブロンか、折りたたんだ行の後ろの `⋯ N 行` ピルをクリックするとマウスで切り替えられます。折りたたまれた行にカーソルが入ると (検索、行へ移動、ブックマーク、取り消す) 展開され、↑ / ↓ は折りたたみを飛び越えます。折りたたみは編集に追従し、セッションの間だけ保持されます。

**スクロールバーマーカー** — エディタの右端の細い帯に、検索の一致 (アクセントカラー)、ブックマーク (警告色)、カーソル行、折りたたんだ見出しが、ファイル内の相対位置に表示されます。書類全体が画面に収まるときは隠れます。**表示 › スクロールバーマーカー** またはレイアウトタブの折りたたみグループでオフにできます。

## 13. エディタ分割

**⌘\\** で同じ書類を 2 つのエディタに左右に並べて表示します。**表示 › 分割 › 上下に分割** で上下に並び、レイアウトタブにも同じボタンがあります。両方のビューは同じテキストを編集し、1 つの取り消し履歴を共有しますが — 一方で入力して他方で ⌘Z — スクロールは独立しているので、ファイルのある部分を読みながら別の部分に書けます。コマンド、ステータスバー、Markdown プレビューは最後にクリックしたエディタに従い、**⌥⌘\\** でもう一方にフォーカスを移します。分割中はステータスバーに **SPLIT** が表示され、もう一度 ⌘\\ で閉じます。

## 14. クイック追加

**クイック追加 (⇧⌘N)** は、今していることを離れずにメモを追加するための小さなフローティングパネルを開きます。メモを入力して **⌘↩** を押すと、書類の末尾に — デフォルトではタイムスタンプ見出し付きで — 追加され、すぐに保存され、1 回で取り消せます。パネルは隠れ、フォーカスは元のアプリに戻ります。**Esc** でパネルを閉じ、下書きは次回まで保持されます。

このパネルは HyperEdit をアクティブにしないので、**グローバルショートカット** — デフォルトでは **⌃⌥N** — で他のどのアプリからでも使えます。設定でオフにしたり、代わりに ⌃⌥Space、⌃⇧Space、⌃⌥⌘N を選んだり、タイムスタンプ見出しをオフにしたりできます。ショートカットはシステムのホットキーサービスを使うので、アクセシビリティの許可は不要です。他のアプリがすでにその組み合わせを使っている場合は、起動時に出力パネルにその旨が表示されます — 別のものを選んでください。

## 15. Markdown プレビューと構文の色分け

- **Markdown プレビュー (⇧⌘P)** はウインドウを分割し、右側に現在のファイルのレンダリング結果を表示します: 見出し、リストとタスクリスト、表、フェンス付きコード、引用、リンク、画像が現在のテーマで装飾されます。エディタのスクロール位置に追従し、入力を止めると少ししてから再レンダリングされます。リンクはブラウザで開き、ファイル内の生の HTML はテキストとして表示されるだけで、実行されることはありません。2 MB を超えるファイルではプレビューの代わりに通知が表示されます。オンの間はステータスバーに **MD** が表示されます。
- **構文の色分け (⌃⌘H)** はファイルの拡張子で決まり、ステータスバーに表示されます。メモと Markdown には軽いルールセット — URL、日付と時刻、見出し、`[タイトル]` 行、リスト記号、`[ ]` / `[x]` のタスクボックス、`#タグ`、`キー:` ラベル、`**太字**`、`` `コード` ``、`⇒ → ->` の矢印 — が適用され、約 20 のプログラミング言語ではコメント、文字列、数値、キーワード、関数名と型名が色分けされます。色は表示中の行にだけ描かれるので、ファイルを変更したり入力を遅くしたりすることはありません。複数行にまたがる構文は、閉じるまで色が続きます: ブロックコメント (`/* */`、`<!-- -->`)、複数行文字列 (Swift と Python の `"""`、JavaScript のテンプレートリテラル、Go の raw 文字列、Rust の `r#"…"#`)、Markdown のフェンス付きコードブロックです。フェンス付きコードブロックは、情報文字列で指定した言語 (```` ```python ````) で色分けされます。開始または終了の区切り記号を入力すると、その下の行がすぐに色分けし直されます。
- **ユーザ定義の文法。** HyperEdit が知らない言語に色を付けたり、組み込みの言語を変えたりするには、`~/Library/Application Support/HyperEdit/grammars/` に `*.json` ファイルを置きます。HyperEdit は初回起動時に、コピーして使える `example.json` と、すべてのキー — `name`、`extensions` または `filenames`、`mode`、`lineComments`、`blockComment`、`strings`、`multilineStrings`、`keywords`、`types`、`constants`、`builtins`、`caseInsensitive` — を説明する README 付きでこのフォルダを作成します。**ファイル › 文法を再読み込み** で再起動せずに変更を適用できます。ステータスバーには文法の名前が表示され、コメント切替 (⌘/) はその文法のコメント記号を使います。解析に失敗したファイルはスキップされ、出力パネルにメッセージが表示されます。

## 16. テーマ、フォント、CJK テキスト

**テーマ。** 22 のパレット — ライト 5、ダーク 17 — がアプリに付属します。デフォルトではシステムの外観に従い、ライトモードでは **Hyper Light**、ダークモードでは **Hyper Dark** になります。テーマを固定するには、レイアウトタブ、ステータスバーのテーマメニュー、**表示 › テーマ**、または ⌥⌘] / ⌥⌘[ で選びます。**システムの外観に合わせる** は同じメニューと設定にあります。同じパレットは Zed エディタでも使えます (各リリースの `hyperedit-themes.json`)。

**カーソルとウインドウの不透明度。** 設定 › **外観** でカーソルの形 — **縦棒** (デフォルト)、**ブロック** (文字のセルがカーソル色で塗られ、文字は読めるまま)、**下線** — と点滅するかどうかを選びます。マルチカーソルと列モードの追加のカーソルも同じ形になります。**ウインドウの不透明度** (50–100 %) はウインドウ全体 — エディタ、リボン、パネル、ステータスバーすべて — を半透明にし、テキスト、アイコン、境界線は不透明のままです。**ウインドウの背後をぼかす** でシステムのぼかしを加えます。表示 › ウインドウの不透明度 には 100 / 90 / 80 / 70 % の段階があります。

**フォント。** HyperEdit はインストールされていれば **Fira Code** を、なければシステムの等幅フォントを使います。韓国語テキストは別のフォント — インストールされていればデフォルトで **D2Coding** — で描画され、ハングル 1 音節がちょうど欧文 2 セル分の幅になるよう拡大縮小されるので、タブで揃えた表が崩れません。合字、行の高さ、両方のフォントファミリー、ハングルの倍率は設定にあります。中国語と日本語のテキストはシステムの代替フォントを使い、列を揃えるでも 2 セルとして数えられます。

## 17. 保存、スナップショット、エンコーディング

- **自動保存** は入力を止めてから 2 秒後に実行されます (⌘S で今すぐ保存)。終了時、ウインドウを閉じるとき、ファイルを切り替えるときは書類が即座に保存されるので、この 2 秒の間に何かが失われることはありません。すべての書き込みはアトミックです。
- **スナップショット。** 各セッションの最初の保存の前に、ファイルのコピーが `~/Library/Application Support/HyperEdit/snapshots` に保存されます (**ファイル › スナップショットフォルダを開く**)。ファイルごとに新しい 20 個が保持され、90 日より古いものは削除されます。
- **外部での変更。** 開いているファイルを別のプログラムが変更し、未保存の編集がなければ、HyperEdit はファイルを再読み込みしてカーソル位置を保ちます。未保存の編集がある場合は、外部の版をスナップショットに保存して警告を表示し、保存すると上書きします。
- **安全性。** 内容のあったファイルに空のバッファが書き込まれることは決してありません。終了時の保存に失敗した場合は、緊急コピーがスナップショットフォルダに書き出され、それでも終了するかどうか尋ねられます。
- **エンコーディング。** ファイルはまず UTF-8、次に EUC-KR (CP949)、CP1252、Latin-1 として読み込まれ、同じエンコーディングで保存されます (UTF-8 の BOM は保持)。元のエンコーディングで表せない文字を入力すると、ファイルは UTF-8 で保存され、ステータスバーにその旨が表示されます。どのエンコーディングでもデコードできないファイルは、壊すのではなく、そもそも開きません。
- **改行コード** (UNIX / DOS / MAC) は検出されて保持されます。クイック追加とテキストツールはファイル自身の改行コードを使います。
- **書き出し。** **ファイル › HTML として書き出す…** は書類を自己完結した 1 つの HTML ファイルとして保存します — Markdown はプレビューと同じようにレンダリングされ、メモとコードは構文の色分けをしたブロックになります。**ファイル › PDF として書き出す…** は同じページをページ分けした PDF に出力します (米国・カナダ・メキシコでは Letter、それ以外では A4。余白 36 pt。ヘッダとフッタなし)。保存パネルでは、テーマ (現在、Hyper Light、Hyper Dark) と、メモとコードの場合は行番号を選べます。書き出したページにはスクリプトが含まれず、ネットワークからスタイルシートやフォントを読み込むこともありません。画像の URL は書かれたとおりに保たれるので、ブラウザ (と PDF のレンダラ) がリモートの画像を取得することがあります。画像の相対パスは、HTML を Markdown ファイルの隣に保存すれば機能します。PDF の書き出しは 2 MB までのファイルで使えます。シークレットブロック (第 23 節) は `••••••••` として書き出されます。

## 21. トラブルシューティング

- **言語が変わらない。** 新しい言語は再起動後に適用されます — 設定の **今すぐ再起動** を使うか、終了して開き直してください。システムの言語が HyperEdit にない言語の場合は英語で表示されます。設定で言語を明示的に選んでください。
- **ファイルが開かない。** バイナリファイルは意図的にデフォルトのアプリで開きます。UTF-8、EUC-KR、CP1252、Latin-1 以外のエンコーディングのテキストファイルは、壊さないために拒否されます。先に別のツールで変換してください。
- **グローバルのクイック追加ショートカットが効かない。** 他のアプリがその組み合わせを使っているか、⌃Space / ⌃⌥Space がシステム設定 › キーボードの入力ソース切り替えに使われている可能性があります。設定で ⌃⌥N か ⌃⌥⌘N を選んでください。起動時に出力パネルに登録結果が表示されます。
- **表の中で韓国語テキストが広すぎる、または狭すぎる。** D2Coding をインストールするか、設定でハングル倍率を調整してください。2:1 幅補正には等幅のハングルフォントが必要です。
- **間違って保存してしまった。** スナップショットフォルダ (**ファイル › スナップショットフォルダを開く**) を開いてください。セッションの最初の保存前に取られたコピーと、外部での変更を検出したときに作られたコピーがあります。
- **リボンにアイコンしか表示されない。** そのタブにはウインドウが狭すぎます。ウインドウを広げるか、アイコンにホバーしてラベルを表示してください。

## 22. 既知の制限

- 構文の色分けはブロックコメント、複数行文字列、Markdown のフェンスを行をまたいで追跡しますが、Rust の raw 文字列を除き、対応するのは開始と終了が同じ文字列区切り記号と、言語ごとに 1 組のブロックコメントだけです。また、ユーザ文法は単語リストで、正規表現のルールはありません。Markdown プレビューはビューであり、エディタではありません。
- マクロはキーボードでの編集だけを記録します (マウス、選択、マルチカーソルのステップは記録しません)。計算と列を揃えるは、単純な算術とタブ / パイプの表だけを扱います。
- スニペット、マクロ、ユーザ文法は JSON ファイルとして編集します。グラフィカルなエディタはありません。
- 書き出しは書類全体だけが対象で、選択範囲や複数ファイルの書き出し、ページやフォントのオプション、PDF の目次はありません。
- シークレットブロックは画面上で隠すだけです: ファイル、自動保存、スナップショットはプレーンテキストで、隠すためのバーで各行の長さがわかり、VoiceOver はテキストをそのまま読み上げます。シークレットのフェンスは左端から始める必要があります (インデントは 4 スペース未満で、リスト項目や引用の中は不可)。また、シークレットブロックの中にフェンス付きブロックを入れるには、外側のフェンスにバッククォートが 4 つ必要です。アプリのロックはウインドウとその内容を VoiceOver からも隠しますが、何も暗号化しません。
- ブロックコメントは入れ子にできません。また、古い Mac 形式 (CR のみ) の改行コードのファイルは行単位で色分けされます。20,000 文字を超える 1 つの段落の中では、ブロックと下線のカーソルは標準の縦棒カーソルに戻ります。
- 折りたたみはセッションの間だけ保持され、ファイルごとには保存されません。折りたたんだ行をまたぐマウスドラッグは、隠れたテキストも選択します。
- 1 行が 1 MB 以上ある書類は、開くのも中を移動するのも遅くなります。「JSON を1行に」は、そのような行を作る前に警告します。
- ローカルファイルのみ。クラウド同期や iOS アプリはまだありません。
- リストにある 11 言語以外は英語にフォールバックします。

## 23. シークレットブロックとアプリのロック

**シークレットブロック。** 情報文字列が `secret` で始まるフェンス付きコードブロックは、エディタで隠されます:

````markdown
```secret bank
login: me@example.com
password: hunter2
```
````

フェンスの間のすべての行は `••••••••` の付いた空白のバーとして描かれます。フェンスの行は表示されたままなので、ブロックがどこにあり、何のためのものかがわかります。ルールは Markdown でもプレーンテキストのファイルでも同じです。カーソルをブロック内に移動する — クリック、↑ / ↓、行へ移動、検索結果、ブックマーク — とブロック全体が表示され、編集できるようになります。カーソルを外に出すと再び隠されます。変わるのは表示だけです: テキストはファイルにそのまま残っているので、検索、置換、取り消し、保存はこれまでどおりに動作します。

- 編集メニューの **シークレットを表示 (⌥⌘S)** はすべてのブロックを一度に表示します。**設定 › シークレット › 再び隠すまでの時間** (10 / 30 / 60 秒、デフォルト 30 秒、または しない) が過ぎると再び隠され、出力パネルに記録されます。その間ステータスバーには `REVEALED` が、N 個のブロックが隠されている間は `•••• N` が表示されます。**編集 › シークレットブロックを隠す** で非表示を完全にオフにできます。
- シークレットの行は、検索結果とファイルから検索のリスト (一致と行番号はそのまま使えます) およびブックマークのプレビューでは `••••••••` と表示され、アウトラインとタイムラインでは省かれ、Markdown プレビューと HTML / PDF の書き出しでは伏せられます。HyperEdit を終了すると、保留中のクリップボード消去がすぐに実行されます。
- **クリップボードの自動消去。** コピーまたはカットがシークレットの行にかかると — マルチカーソルや列モードでのコピーも含めて — **設定 › シークレット › シークレットのコピー後にクリップボードを消去** (オフ / 10 / 30 / 60 秒、デフォルト 30 秒) の後にクリップボードが消去されます。ただし、その間に別のものをコピーした場合は消去しません。**編集 › クリップボードを消去** ですぐに消去でき、非表示をオフにすると自動消去もオフになります。
- シークレットブロックは、他のフェンス付きブロックと同じように折りたためます (⌥⌘←)。

> 隠すことは暗号化ではありません。ファイル、自動保存、スナップショットはプレーンテキストで、ファイルを持っている人なら誰でもシークレットを読めます。この機能は、作業中にシークレットが画面、スクリーンショット、検索結果、プレビュー、書き出しに現れないようにするものです。

**アプリのロック (Touch ID)。** **HyperEdit › HyperEdit をロック (⌃⌘L)** (アプリケーションメニューの 設定… の下) は、ウインドウ全体 — リボン、サイドバー、エディタ、パネル、ステータスバー — を現在のテーマの不透明なロック画面で覆い、開いている設定ウインドウを閉じ、クイック追加のパネルを隠します。ロック中は、書類について何も — ファイル名さえも — 表示されません。**ロック解除** をクリック (または Return か Space を押す) すると **Touch ID** で認証します。Touch ID に失敗した場合や Mac に Touch ID がない場合は、macOS がログインパスワードで代用します。ロックすると、開いているシートや警告も閉じ、表示中のシークレットを再び隠し、保留中のクリップボード消去をすぐに実行します。キャンセルすると HyperEdit はロックされたままで、ボタンで再試行できます。

- **設定 › アプリのロック。** *HyperEdit を開くときに Touch ID またはパスワードを要求* (デフォルトはオフ) を有効にすると、アプリはロックされた状態で起動します: 書類は読み込まれ、自動保存も動き続けますが、認証するまで何も表示されません。*操作がないときにロック* (しない / 1 / 5 / 15 / 30 分、デフォルトは しない) は、HyperEdit でキー入力やクリックがその時間なかったときにロックします。起動時のオプションとは独立しています。*Mac のスリープ時または画面のロック時にロック* (デフォルトはオン) は、起動時のオプションがオンの間に適用され、ディスプレイのスリープも対象になります。この Mac で Touch ID を使えるかどうかは説明文に表示されます。
- ロック中はキーボード入力が無視され、メニューバーも開けません。使えるのは ⌘Q、⌘H / ⌥⌘H、⌘M、⌘W、⌃⌘F と Dock メニューだけです。クイック追加のグローバルショートカットは、パネルの代わりにロック解除の画面を表示し、認証するとパネルを開きます。
- これは画面のためのプライバシーロックであり、暗号化ではありません: ディスク上のファイルは変わらず、他のどのアプリからも読めます。*要求…* のオプションは、Mac に Touch ID もログインパスワードもない間はオンにできないので、自分を締め出してしまうことはありません。
