## 1. 설치와 업데이트

**요구 사항:** macOS 15 (Sequoia) 이상. 앱은 유니버설 바이너리(Apple Silicon·Intel)이며 서명·공증되어 있어 Gatekeeper 경고 없이 열립니다.

**Homebrew**

```sh
brew tap Hyeongcheol-An/tap
brew install --cask hyperedit
```

이후 업데이트는 `brew upgrade --cask hyperedit`로 합니다. Homebrew 7에서는 먼저 tap을 신뢰하라고 물을 수 있습니다: `brew trust Hyeongcheol-An/tap`.

**DMG:** [GitHub Releases](https://github.com/Hyeongcheol-An/HyperEdit/releases)에서 `HyperEdit-x.y.z-universal.dmg`를 내려받아 열고 `HyperEdit.app`을 `Applications`로 드래그합니다. 내려받은 파일을 검증하려면 `SHA256SUMS`를 DMG 옆에 두고 `shasum -a 256 -c SHA256SUMS`를 실행하세요.

HyperEdit에는 네트워크 코드도 텔레메트리도 없습니다: 어디에도 접속하지 않으며, 업데이트는 앱이 알아서 하는 일이 아니라 사용자가 직접 하는 일입니다.

## 2. 첫 실행

HyperEdit는 `~/Documents/HyperEdit/notes.md`를 엽니다. 파일이 없으면 사용자 언어로 된 짧은 환영문과 함께 새로 만듭니다 — 그 글을 지우고 쓰기 시작하면 됩니다. 파일 하나를 두고 계속 덧붙여 쓰는 것이 기본 발상이지만, 꼭 그래야 하는 것은 아닙니다:

- **⌘N**은 새 빈 텍스트 파일을 만듭니다(이름과 폴더를 고릅니다).
- **⌘O**는 다른 텍스트 파일을 엽니다. 마지막으로 연 파일은 다음 실행 때 기억됩니다.
- **파일 › 기본 문서 열기**는 `notes.md`로 돌아갑니다.
- 바이너리 파일(이미지, PDF, 압축 파일 등)은 에디터로 불러오지 않고 기본 앱으로 엽니다.

캐럿과 스크롤 위치는 파일별로 기억되므로, 30,000줄짜리 파일을 다시 열어도 마지막 자리로 돌아갑니다. **⌃⌘E**는 문서 끝으로 이동합니다 — 메모 파일에서 보통 가고 싶은 바로 그 자리입니다.

## 3. 인터페이스 언어

인터페이스는 열한 가지 언어로 제공됩니다: English(영어), 한국어, 简体中文(중국어 간체), 日本語(일본어), Tiếng Việt(베트남어), हिन्दी(힌디어), Deutsch(독일어), Français(프랑스어), Español(스페인어), Português(포르투갈어, 브라질 표기), العربية(아랍어). 아랍어 텍스트는 오른쪽에서 왼쪽으로 쓰이지만, 창 배치 — 리본, 사이드바, 패널, 편집기 — 는 대부분의 코드 에디터처럼 왼쪽에서 오른쪽으로 그대로이고, 입력하는 텍스트는 고유의 방향을 따릅니다.

기본으로 HyperEdit는 시스템 언어를 따릅니다. 다른 언어를 고르려면:

1. **설정(⌘,)**을 열고 맨 위의 **언어** 섹션을 봅니다.
2. **인터페이스 언어** 메뉴에서 언어를 고릅니다. 각 언어는 그 언어의 문자로 표시되므로, 현재 언어가 낯설어도 자기 언어를 찾을 수 있습니다. **시스템 기본값**은 시스템 설정이 가리키는 언어를 함께 보여 줍니다.
3. **지금 재실행**을 클릭합니다. 문서를 먼저 저장한 뒤 HyperEdit가 종료되고 새 언어로 다시 열립니다. (계속 작업하다가 나중에 재실행해도 됩니다. 선택은 이미 저장되어 있습니다.)

선택은 **시스템 설정 › 일반 › 언어 및 지역 › 응용 프로그램**과 같은 곳에 저장되므로 두 설정은 항상 일치합니다. **도움말 › 사용자 가이드**와 설정의 **사용자 가이드 열기** 버튼은 현재 인터페이스 언어로 이 가이드를 엽니다.

목록에 없는 언어(예: 중국어 번체)는 영어로 표시됩니다. 문서 텍스트, 파일 이름, 삽입하는 날짜는 인터페이스 언어의 영향을 받지 않습니다 — 타임스탬프의 요일은 시스템 로케일을 따릅니다.

## 4. 창 구성

레이아웃은 고전적인 리본 에디터를 따르며 제목 표시줄은 숨겨져 있습니다.

- **리본 탭** — **홈**(클립보드, 찾기, 삽입, 모드, 파일), **편집**(줄, 대소문자, 정렬, 공백, 열·멀티 커서, 도구, 매크로), **레이아웃**(테마, 패널, 접기, 마크다운, 글꼴), **고급**(설정, 스냅샷 폴더, 다시 읽기, 기본 문서), **창**(전체 화면, 패널). 창이 좁으면 오른쪽 그룹부터 아이콘으로 접히며, 아이콘의 툴팁에 라벨이 표시됩니다.
- **문서 탭 줄** — 현재 파일 이름과 새 문서(⌘N)·열기(⌘O) 버튼, 그리고 빠른 실행 저장 / 실행 취소 / 다시 실행.
- **사이드바(⌘1)** — **파일**(현재 파일의 폴더. 한 번 클릭으로 파일을 엽니다), **아웃라인(⌘3)**(헤딩, `[제목]` 줄, 번호 항목. 필터 상자가 있고 현재 항목이 강조됩니다), **타임라인(⌘4)**(타임스탬프 헤딩을 월별로 묶어 최신순으로).
- **하단 패널(⌘2)** — **찾기 결과**, **북마크**, 그리고 앱이 한 일(저장, 바꾸기, 오류)의 기록인 **출력**.
- **상태바** — 줄과 열(선택 중이면 선택 길이도. 문자 오프셋은 마우스를 올리면 표시), 줄바꿈 종류(UNIX / DOS / MAC), 파일 인코딩, 열 모드가 켜져 있으면 **COL**, 커서 수, 줄 수 · 파일 크기, 최근 상태 메시지, 구문 언어(구문 색이 꺼져 있으면 흐리게), 테마 메뉴(시스템 외형을 따르는 동안 "· 시스템" 표시), 확대 비율. 대부분 클릭할 수 있습니다.

## 5. 편집 기본

- 수 MB 파일에서도 타이핑이 빠릅니다. 문서에서 보이는 부분만 레이아웃하기 때문입니다.
- **자동 줄바꿈** ⌥Z · **줄 번호** ⌥⌘L · **확대/축소** ⌘= / ⌘- / ⌘0 (레이아웃 탭에도 있습니다).
- **줄로 이동** ⌘L · **문서 끝으로** ⌃⌘E.
- **날짜/시간 삽입** F7은 `## 2026-10-31 (토) 14:05` 같은 타임스탬프 헤딩을 삽입합니다. 요일은 시스템 로케일을 따릅니다. 이런 줄이 타임라인에 모입니다.
- 현재 줄은 강조되고, 거터의 그 줄 번호는 본문 글자색으로 표시됩니다.
- 실행 취소와 다시 실행은 세션 안에서 무제한이며, 아래의 모든 도구는 실행 취소 한 단계입니다.

## 6. 찾기와 바꾸기

- **찾기(⌘F)**는 찾기 바를 엽니다. 검색어를 입력하고 Enter를 누르면 모든 매치가 줄 번호와 함께 하단 패널에 나열되고, 목록이 열려 있는 동안 편집기 안의 매치도 강조됩니다. 토글: 정규식 `.*`, 대소문자 구분 `Aa`, 단어 단위 `W`. **F3 / ⇧F3**으로 다음 / 이전 매치로 이동합니다. 편집하면 약 1초 뒤 목록이 스스로 새로 고쳐집니다.
- **바꾸기(⌘R)**는 바꿀 내용 입력란을 추가합니다: 현재 매치를 바꾸고 다음으로 넘어가거나 **모두 바꾸기**를 합니다. 정규식이 켜져 있으면 `$1` 같은 템플릿으로 캡처 그룹을 넣습니다. 모두 바꾸기는 매치가 수천 개여도 실행 취소 한 단계입니다.
- **파일에서 찾기(⇧⌘F)**는 폴더(하위 폴더 포함)를 검색합니다. 폴더를 고르고, 필요하면 `*.md;*.txt` 같은 마스크로 범위를 좁힌 뒤, 결과를 클릭하면 그 파일의 그 줄이 열립니다. 숨김 파일, 패키지, 바이너리 파일, 20 MB가 넘는 파일은 건너뜁니다.
- **매치 모두 선택(⌥⌘A)**은 모든 매치를 커서로 바꿉니다 — 아래의 멀티 커서 참고.

## 7. 북마크

**⌘F2**는 현재 줄을 북마크하고(또는 북마크를 제거하고), **F2 / ⌥F2**는 다음 / 이전 북마크로 이동하며, 하단 패널의 **북마크** 탭에 전부 나열됩니다. 거기서 북마크에 이름을 붙일 수 있습니다. 북마크는 편집을 따라갑니다: 위에 줄을 넣거나 지우면 함께 움직이고, 북마크한 줄을 지우면 사라지며, 실행 취소하면 되돌아옵니다. `~/Library/Application Support/HyperEdit/bookmarks/`에 문서별로 저장되므로 문서 옆에는 아무것도 쓰지 않습니다.

## 8. 열 모드와 멀티 커서

- **열 모드(⌥C)** — ⌥를 누른 채 드래그하거나 ⇧+방향키로 사각형을 선택합니다. 그러면 입력과 삭제가 블록의 모든 줄에 적용되고, 짧은 줄은 가상 공백으로 채워지며, 복사 / 붙여넣기는 줄 단위로 동작합니다. 상태바에 **COL**이 표시됩니다. ⌥C를 다시 누르면 꺼집니다.
- **숫자 채우기(⌥⌘N)** — 열 선택(또는 모든 커서)에 순번을 채웁니다: 시작 값과 증가 값을 고르면, 숫자는 같은 자릿수가 되도록 0으로 채워집니다.
- **멀티 커서** — ⌘-클릭으로 커서를 추가하고, **⌘D**는 선택한 텍스트(또는 캐럿이 있는 단어)의 다음 등장을 추가하며, **⌥⌘A**는 모든 검색 매치를 선택합니다. 입력은 모든 커서에 들어가고, Esc를 누르면 커서 하나로 돌아갑니다. 모든 멀티 커서 편집은 실행 취소 한 단계입니다.

## 9. 줄과 텍스트 도구

이 도구들은 **편집** 리본 탭과 **줄** 메뉴에 있습니다. 선택한 줄에, 선택이 없으면 현재 줄에 적용됩니다.

| 그룹 | 도구 |
|---|---|
| 줄 | 줄 삭제 ⇧⌘K · 줄 복제 ⇧⌘D · 줄 위로 / 아래로 이동 ⌥↑ / ⌥↓ · 줄 합치기 ⇧⌘J · 역순 · 줄 번호 붙이기 |
| 대소문자 | 대문자 · 소문자 · 첫 글자 대문자 · 대소문자 반전 |
| 정렬 | 오름차순 · 내림차순 · 숫자 정렬(각 줄 앞의 숫자 기준) · 중복 줄 제거 |
| 공백 | 뒤 공백 제거 · 앞뒤 공백 제거 · 빈 줄 제거 · 탭 → 공백 · 공백 → 탭 |

- **계산(⌃⌘=)**은 선택 영역, 또는 현재 줄(`=`이 있으면 마지막 `=` 뒤 부분)을 계산해 ` ⇒ 결과`를 붙입니다: `3+0.5+0.25`는 `3+0.5+0.25 ⇒ 3.75`가 됩니다. 수식을 고친 줄에서 다시 실행하면 옛 결과를 바꿉니다. 지원: `+ - * / % ^`, 괄호, `1,234`와 `1_000` 형식의 숫자, `sqrt abs round floor ceil min max`, `pi`와 `e`. 계산할 수 없는 식은 출력 패널에 알리고 텍스트는 그대로 둡니다.
- **열 맞춤(⌃⌘T)**은 탭으로 구분된 열(선택한 줄, 또는 캐럿 주변의 탭 줄 묶음)을 공백으로 채워 모든 열이 같은 표시 열에서 시작하게 합니다. 한글·중국어·일본어 글자는 두 칸으로 셉니다. 모든 줄에 `|`가 있으면 대신 마크다운 표로 다룹니다: 셀을 ` | ` 안에서 채우고, `---` 줄은 다시 그리며, `--:` 열은 오른쪽 정렬합니다.
- **주석 토글(⌘/)**은 파일 종류의 주석 기호로 줄을 주석 처리하거나 해제합니다: 코드는 `//`, `#`, `--` 등, 마크다운과 HTML은 `<!-- -->`, CSS는 `/* */`, 일반 메모는 `//`. 비어 있지 않은 줄이 전부 이미 주석이면 모두 해제하고, 아니면 모두 주석 처리하며, 기호는 가장 얕은 들여쓰기에 맞춰 정렬됩니다. 빈 줄은 건너뜁니다.
- **JSON 정리(⌃⌘J) / JSON 한 줄로**는 선택 영역, 또는 선택이 없으면 문서 전체를 보기 좋게 정리하거나(들여쓰기 2칸) 한 줄로 줄입니다. 키 순서와 숫자 표기는 그대로 두고, ASCII가 아닌 텍스트는 이스케이프하지 않으며, 입력에 주석과 뒤따르는 쉼표(JSONC)가 있어도 됩니다. 문법 오류가 있으면 텍스트는 그대로 두고 출력 패널에 `줄:열`을 표시한 뒤 캐럿을 그 자리로 옮깁니다.

## 10. 스니펫

트리거 단어를 치고 **Tab**을 누르면 펼쳐집니다. 내장 트리거: `todo`, `date`, `time`, `now`, `meeting`, `table`, `link`, `code`. **스니펫 삽입…(⇧⌘I)**은 필터 상자와 함께 전부 나열하고, 홈 탭에는 스니펫… 버튼이 있습니다.

스니펫 본문에는 변수 — `${date}`, `${time}`, `${datetime}`, `${selection}`, `${clipboard}`, `${filename}` — 와 탭스톱 `$1` … `$9`, `${1:placeholder}`, `$0`을 쓸 수 있습니다. 펼친 뒤에는 Tab / ⇧Tab으로 탭스톱 사이를 오가고(같은 번호를 두 번 쓰면 멀티 커서가 됩니다), Esc나 클릭으로 세션을 끝냅니다.

**스니펫 편집…**(편집 메뉴 또는 홈 탭)은 `~/Library/Application Support/HyperEdit/snippets.json`을 HyperEdit 자신으로 엽니다. 각 항목에는 `trigger`, `name`, `body`가 있으며, 저장하면 파일을 다시 읽으므로 새 트리거가 바로 동작합니다.

## 11. 매크로

매크로는 입력한 것을 기록해 두었다가 다른 곳에서 다시 재생합니다.

1. **매크로 기록(⇧⌘M)**으로 기록을 시작하면 상태바에 `● REC`가 표시됩니다. 타이핑(한국어 등 IME는 확정된 글자), 캐럿 이동, 삭제, 줄바꿈, 붙여넣기, 텍스트 도구, 다음 찾기(F3, 검색어 포함)가 기록됩니다. 마우스 클릭, 선택 변경, 멀티 커서 편집은 기록되지 않습니다.
2. **⇧⌘M**을 다시 누르면 기록이 멈춥니다.
3. **매크로 재생(⌥⌘M)**은 캐럿 위치에서 재생합니다. **매크로 여러 번 재생…**은 최대 10,000회 반복하며, 찾기 단계가 아무것도 찾지 못하거나 한 바퀴에 아무 변화가 없으면 스스로 멈춥니다 — "모든 줄에 이것을 적용"하기에 편리한 도구입니다. 전체 재생은 실행 취소 한 단계입니다.

마지막 기록은 종료할 때까지 메모리에만 있으므로, 기록 중에 입력한 민감한 내용은 디스크에 남지 않습니다. **마지막 매크로 이름 붙여 저장…**은 그것을 **매크로** 메뉴에 영구히 추가합니다. 저장된 매크로는 `~/Library/Application Support/HyperEdit/macros/macros.json`에 있으며, **매크로 파일 편집…**으로 편집기에서 엽니다.

## 12. 코드 접기와 스크롤바 마커

**접기(⌥⌘←) / 펼치기(⌥⌘→)**는 캐럿이 있는 영역을 숨기거나 보이고, **⌥⇧⌘← / ⌥⇧⌘→**는 전부 접거나 펼칩니다. 영역은 다음과 같습니다:

- 현재 줄 아래에 더 깊이 들여쓴 줄들(빈 줄 무시),
- 마크다운에서는 `#` 헤딩 아래부터 같거나 높은 레벨의 다음 헤딩 직전까지(펜스 코드 블록도 접힙니다),
- 코드에서는 `{`, `[`, `(`로 끝나는 줄부터 닫는 괄호 줄까지.

거터의 화살표나 접힌 줄 뒤의 `⋯ N줄` 표식을 클릭하면 마우스로 접고 펼칩니다. 캐럿이 접힌 줄로 들어가면(찾기, 줄로 이동, 북마크, 실행 취소) 펼쳐지고, ↑ / ↓는 접힌 구간을 건너뜁니다. 접힘은 편집을 따라가며 세션 동안 유지됩니다.

**스크롤바 마커** — 편집기 오른쪽 가장자리의 얇은 띠에 검색 매치(강조색), 북마크(경고색), 캐럿 줄, 접힌 머리 줄이 파일 안의 상대 위치로 표시됩니다. 문서 전체가 한 화면에 들어가면 숨겨집니다. **보기 › 스크롤바 마커** 또는 레이아웃 탭의 접기 그룹에서 끌 수 있습니다.

## 13. 편집기 분할

**⌘\\**는 같은 문서를 두 편집기로 좌우에 나란히 보여 줍니다. **보기 › 분할 › 상하로 분할**은 위아래로 놓고, 레이아웃 탭에도 같은 버튼이 있습니다. 두 뷰는 같은 텍스트를 편집하고 하나의 실행 취소 기록을 공유하지만 — 한쪽에서 입력하고 다른 쪽에서 ⌘Z — 스크롤은 따로 하므로, 파일의 한 부분을 읽으면서 다른 부분에 쓸 수 있습니다. 명령, 상태바, 마크다운 미리보기는 마지막으로 클릭한 편집기를 따르며, **⌥⌘\\**는 포커스를 다른 쪽으로 옮깁니다. 분할이 켜져 있는 동안 상태바에 **SPLIT**이 표시되고, ⌘\\를 다시 누르면 닫힙니다.

## 14. 빠른 추가

**빠른 추가(⇧⌘N)**는 하던 일을 멈추지 않고 메모를 덧붙일 수 있는 작은 떠 있는 창을 엽니다. 메모를 쓰고 **⌘↩**를 누르면 문서 끝에 — 기본으로 타임스탬프 헤딩과 함께 — 덧붙여지고 바로 저장되며, 실행 취소 한 번으로 되돌릴 수 있습니다. 그런 다음 창은 숨겨지고 포커스는 쓰던 앱으로 돌아갑니다. **Esc**는 창을 닫고 초안을 다음을 위해 남겨 둡니다.

이 창은 HyperEdit를 활성화하지 않으므로 **전역 단축키**로 다른 어떤 앱에서도 쓸 수 있습니다: 기본값은 **⌃⌥N**입니다. 설정에서 끄거나 ⌃⌥Space, ⌃⇧Space, ⌃⌥⌘N 중 하나로 바꿀 수 있고, 타임스탬프 헤딩도 끌 수 있습니다. 단축키는 시스템 핫키 서비스를 쓰므로 손쉬운 사용 권한이 필요 없습니다. 다른 앱이 이미 그 조합을 쓰고 있으면 실행할 때 출력 패널에 알려 주니 다른 조합을 고르세요.

## 15. 마크다운 미리보기와 구문 색

- **마크다운 미리보기(⇧⌘P)**는 창을 분할해 오른쪽에 현재 파일을 렌더링한 화면을 보여 줍니다: 헤딩, 목록과 체크리스트, 표, 펜스 코드, 인용, 링크, 이미지가 현재 테마로 꾸며집니다. 편집기의 스크롤 위치를 따라가고, 입력을 멈추면 잠시 뒤 다시 렌더링합니다. 링크는 브라우저로 열리고, 파일 안의 원시 HTML은 실행되지 않고 글자로 표시됩니다. 2 MB가 넘는 파일은 미리보기 대신 안내 문구를 표시합니다. 켜져 있는 동안 상태바에 **MD**가 표시됩니다.
- **구문 색(⌃⌘H)**은 파일 확장자로 고르고 상태바에 표시합니다. 메모와 마크다운에는 가벼운 규칙 — URL, 날짜와 시각, 헤딩, `[제목]` 줄, 목록 기호와 `[ ]` / `[x]` 체크박스, `#태그`, `키:` 라벨, `**굵게**`, `` `코드` ``, `⇒ → ->` 화살표 — 만 적용되고, 프로그래밍 언어 20여 종에는 주석, 문자열, 숫자, 키워드, 함수와 타입 이름이 칠해집니다. 색은 보이는 줄에만 입히므로 파일을 바꾸거나 타이핑을 느리게 하는 일이 없습니다. 색 입히기는 줄 단위라서, 여러 줄에 걸친 주석이나 문자열은 시작한 줄만 칠해집니다.

## 16. 테마, 폰트, CJK 텍스트

**테마.** 라이트 5개, 다크 17개 — 22개 팔레트가 앱에 들어 있습니다. 기본으로는 시스템 외형을 따릅니다: 라이트 모드에서는 **Hyper Light**, 다크 모드에서는 **Hyper Dark**. 레이아웃 탭, 상태바의 테마 메뉴, **보기 › 테마**, 또는 ⌥⌘] / ⌥⌘[로 테마를 고르면 그 테마로 고정되고, **시스템 외형 따르기**는 같은 메뉴와 설정에 있습니다. 같은 팔레트를 Zed 에디터에서도 쓸 수 있습니다(모든 릴리스에 첨부되는 `hyperedit-themes.json`).

**폰트.** HyperEdit는 **Fira Code**가 설치되어 있으면 그것을, 없으면 시스템 고정폭 폰트를 씁니다. 한글은 별도 폰트 — 설치되어 있으면 기본 **D2Coding** — 로 그리되 한글 한 글자가 정확히 영문 두 칸 폭이 되도록 배율을 맞추므로, 탭으로 맞춘 표가 어긋나지 않습니다. 리거처, 줄 높이, 두 폰트 패밀리, 한글 배율은 설정에 있습니다. 중국어와 일본어 텍스트는 시스템 폴백 폰트를 쓰며, 열 맞춤에서도 두 칸으로 셉니다.

## 17. 저장, 스냅샷, 인코딩

- **자동 저장**은 입력을 멈추고 2초 뒤에 실행됩니다(⌘S는 즉시 저장). 종료, 창 닫기, 파일 전환 시에는 문서를 바로 저장하므로 2초 사이의 편집이 사라지지 않습니다. 모든 쓰기는 원자적입니다.
- **스냅샷.** 세션마다 첫 저장 전에 파일 사본을 `~/Library/Application Support/HyperEdit/snapshots`에 보관합니다(**파일 › 스냅샷 폴더 열기**). 파일별로 최신 20개를 유지하고 90일이 지난 것은 지웁니다.
- **외부 변경.** 파일이 열려 있는 동안 다른 프로그램이 파일을 바꿨고 저장하지 않은 편집이 없으면, HyperEdit는 파일을 다시 읽되 캐럿 위치는 유지합니다. 저장하지 않은 편집이 있으면 외부본을 스냅샷으로 보관하고 경고를 표시하며, 그 뒤 저장하면 덮어씁니다.
- **안전장치.** 빈 버퍼를 내용이 있던 파일 위에 덮어쓰지 않습니다. 종료할 때 저장에 실패하면 비상 사본을 스냅샷 폴더에 쓰고 그래도 종료할지 묻습니다.
- **인코딩.** 파일은 UTF-8, 그다음 EUC-KR(CP949), CP1252, Latin-1 순으로 읽고 같은 인코딩으로 저장합니다(UTF-8 BOM은 보존). 원래 인코딩에 담을 수 없는 문자를 입력하면 파일을 UTF-8로 저장하고 상태바에 알립니다. 이 인코딩 중 어느 것으로도 읽을 수 없는 파일은 망가뜨리지 않도록 아예 열지 않습니다.
- **줄바꿈 종류**(UNIX / DOS / MAC)는 감지해 보존하며, 빠른 추가와 텍스트 도구도 파일의 것을 그대로 씁니다.

설정은 **⌘,** 또는 고급 탭에서 엽니다.

| ⌥⌘] / ⌥⌘[ | 다음 / 이전 테마 | ⌘= / ⌘- / ⌘0 | 확대 / 축소 / 기본 |
| ⌘, | 설정 | ⌘Q | 종료(먼저 저장) |

## 20. HyperEdit가 쓰는 파일

HyperEdit는 사용자가 연 파일과 자기 데이터만 건드립니다:

| 경로 | 내용 |
|---|---|
| `~/Documents/HyperEdit/notes.md` | 기본 문서(없으면 첫 실행 때 생성) |
| `~/Library/Application Support/HyperEdit/snapshots/` | 저장 전 스냅샷과 비상 사본 |
| `~/Library/Application Support/HyperEdit/bookmarks/` | 북마크한 문서마다 JSON 파일 하나 |
| `~/Library/Application Support/HyperEdit/snippets.json` | 사용자 스니펫 |
| `~/Library/Application Support/HyperEdit/macros/macros.json` | 저장한 매크로 |
| `~/Library/Preferences/io.github.hyeongcheol-an.hyperedit.plist` | 환경설정(인터페이스 언어 포함) |

문서 옆에는 아무것도 쓰지 않으며, 아무것도 Mac 밖으로 나가지 않습니다.

## 21. 문제 해결

- **언어가 바뀌지 않습니다.** 새 언어는 재실행 뒤에 적용됩니다 — 설정의 **지금 재실행**을 쓰거나 종료 후 다시 여세요. 시스템 언어가 HyperEdit에 없는 언어면 영어로 표시되니, 설정에서 언어를 직접 고르세요.
- **파일이 열리지 않습니다.** 바이너리 파일은 의도적으로 기본 앱에서 엽니다. UTF-8, EUC-KR, CP1252, Latin-1 이외의 인코딩으로 된 텍스트 파일은 망가뜨리지 않도록 열기를 거부하니, 먼저 다른 도구로 변환하세요.
- **빠른 추가의 전역 단축키가 동작하지 않습니다.** 다른 앱이 그 조합을 쓰고 있거나, 시스템 설정 › 키보드에서 ⌃Space / ⌃⌥Space가 입력 소스 전환에 쓰이고 있을 수 있습니다. 설정에서 ⌃⌥N이나 ⌃⌥⌘N을 고르세요. 출력 패널이 실행할 때 등록 결과를 알려 줍니다.
- **표에서 한글이 너무 넓거나 좁게 보입니다.** D2Coding을 설치하거나 설정에서 한글 배율을 조정하세요. 2:1 폭 보정에는 고정폭 한글 폰트가 필요합니다.
- **실수로 저장했습니다.** 스냅샷 폴더(**파일 › 스냅샷 폴더 열기**)를 여세요. 세션의 첫 저장 전에 떠 둔 사본과, 외부 변경을 감지했을 때 만든 사본이 거기 있습니다.
- **리본에 아이콘만 보입니다.** 그 탭에 비해 창이 너무 좁습니다. 창을 넓히거나 아이콘에 마우스를 올려 라벨을 확인하세요.

## 22. 알려진 제한

- 구문 색은 줄 단위이며 사용자 정의 문법은 없습니다. 마크다운 미리보기는 보기 전용이며 편집기가 아닙니다.
- 매크로는 키보드 편집만 기록합니다(마우스, 선택, 멀티 커서 단계 없음). 계산과 열 맞춤은 산술식과 탭 / 파이프 표에만 동작합니다.
- 스니펫과 매크로는 JSON 파일로 편집합니다. 그래픽 편집기는 없습니다.
- 접힘은 세션 동안만 유지되고 파일별로 저장되지 않습니다. 접힌 줄을 지나는 마우스 드래그는 숨은 텍스트도 선택합니다.
- 한 줄이 1 MB 이상인 문서는 열고 이동하는 것이 느립니다. JSON 한 줄로는 그런 결과를 만들기 전에 경고합니다.
- 로컬 파일만 다룹니다. 클라우드 동기화와 iOS 앱은 아직 없습니다.
- 위의 열한 가지 이외의 언어는 영어로 표시됩니다.
