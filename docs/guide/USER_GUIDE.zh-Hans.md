## 1. 安装与更新

**系统要求：** macOS 15 (Sequoia) 或更高版本。应用为通用二进制（Apple 芯片和 Intel），已签名并经过公证，因此 Gatekeeper 会直接打开它而不显示警告。

**Homebrew**

```sh
brew tap Hyeongcheol-An/tap
brew install --cask hyperedit
```

之后可用 `brew upgrade --cask hyperedit` 更新。Homebrew 7 可能会要求你先信任该 tap：`brew trust Hyeongcheol-An/tap`。

**DMG：** 从 [GitHub Releases](https://github.com/Hyeongcheol-An/HyperEdit/releases) 下载 `HyperEdit-x.y.z-universal.dmg`，打开后将 `HyperEdit.app` 拖到 `Applications`（应用程序）文件夹。要校验下载文件，把 `SHA256SUMS` 放在 DMG 旁边并运行 `shasum -a 256 -c SHA256SUMS`。

HyperEdit 没有任何网络代码，也没有遥测：它从不回传数据，更新由你自己完成，而不是它自动进行。

## 2. 首次启动

HyperEdit 会打开 `~/Documents/HyperEdit/notes.md`。如果该文件不存在，会用你所用语言的一段简短欢迎文字创建它——删除这段文字即可开始书写。设计理念是只保留一个文件并不断追加内容，但这并非强制：

- **⌘N** 新建一个空文本文件（由你选择名称和文件夹）。
- **⌘O** 打开任意其他文本文件。最近打开的文件会在下次启动时记住。
- **文件 › 打开默认文稿** 带你回到 `notes.md`。
- 二进制文件（图像、PDF、归档文件……）绝不会载入编辑器；它们会改用默认应用打开。

光标和滚动位置按文件记忆，因此重新打开一个 30,000 行的文件会回到你上次离开的位置。**⌃⌘E** 跳到文稿末尾——在笔记文件中这通常正是你想去的地方。

## 3. 界面语言

界面提供十一种语言：English（英语）、한국어（韩语）、简体中文、日本語（日语）、Tiếng Việt（越南语）、हिन्दी（印地语）、Deutsch（德语）、Français（法语）、Español（西班牙语）、Português（葡萄牙语，巴西拼写）和 العربية（阿拉伯语）。阿拉伯语文本从右向左书写，但窗口布局——功能区、边栏、面板和编辑器——与大多数代码编辑器一样保持从左向右；你输入的文本遵循其自身的书写方向。

默认情况下 HyperEdit 跟随系统语言。要选择其他语言：

1. 打开**设置 (⌘,)**，查看顶部的**语言**部分。
2. 从**界面语言**菜单中选择一种语言。每种语言都以其自身文字列出，即使当前语言你不熟悉，也能找到自己的语言。**系统默认**会显示系统设置将为你选择的语言。
3. 点按**立即重新启动**。文稿会先存储，然后 HyperEdit 退出并以新语言重新打开。（你也可以继续工作、稍后再重新启动；选择已经保存。）

该选择存储在与**系统设置 › 通用 › 语言与地区 › 应用程序**相同的位置，因此两者保持一致。**帮助 › 用户指南**和设置中的**打开用户指南**按钮会以当前界面语言打开本指南。

不在列表中的语言会回退到英语（例如繁体中文）。文稿文本、文件名和你插入的日期不受界面语言影响——时间戳中的星期跟随系统区域设置。

## 4. 窗口

布局沿用经典的功能区式编辑器，并隐藏了标题栏。

- **功能区标签页** — **开始**（剪贴板、查找、插入、模式、文件）、**编辑**（行、大小写、排序、空白、列与多光标、工具、宏）、**布局**（主题、面板、折叠、Markdown、字号）、**高级**（设置、快照文件夹、重新载入、默认文稿）、**窗口**（全屏、面板）。窗口较窄时，各组从右侧起折叠为图标；图标的工具提示会显示标签。
- **文稿标签栏** — 当前文件名，带新建 (⌘N) 和打开 (⌘O) 按钮，以及快速访问的存储 / 撤销 / 重做。
- **边栏 (⌘1)** — **文件**（当前文件所在的文件夹；点按一下即可打开文件）、**大纲 (⌘3)**（标题、`[标题]` 行和编号项，带过滤框；当前项会高亮显示）、**时间线 (⌘4)**（按月分组的时间戳标题，最新的在前）。
- **底部面板 (⌘2)** — **查找结果**、**书签**和**输出**，后者是应用所做操作的日志（存储、替换、错误）。
- **状态栏** — 行与列（加上选中长度；悬停可查看字符偏移量）、换行符 (UNIX / DOS / MAC)、文件编码、列模式开启时的 **COL**、光标数量、行数 · 文件大小、最新状态消息、语法语言（语法着色关闭时变暗）、主题菜单（跟随系统外观时标有“· 系统”）以及缩放百分比。大多数项目都可点按。

## 5. 编辑基础

- 在数兆字节的文件中，普通输入依然快速；只对文稿的可见部分进行排版。
- **自动换行** ⌥Z · **行号** ⌥⌘L · **缩放** ⌘= / ⌘- / ⌘0（也在“布局”标签页中）。
- **跳转到行** ⌘L · **文稿末尾** ⌃⌘E。
- **插入日期/时间** F7 插入形如 `## 2026-10-31 (周五) 14:05` 的时间戳标题。星期跟随系统区域设置。这样的行会为时间线提供内容。
- 当前行会高亮显示，行号栏以文本颜色显示其行号。
- 在一次会话内撤销和重做不限次数，下面的每个工具都是单个撤销步骤。

## 6. 查找与替换

- **查找 (⌘F)** 打开查找栏。输入内容并按 Enter：每个匹配都会连同行号列在底部面板中，列表打开期间匹配在编辑器中高亮显示。开关：正则表达式 `.*`、区分大小写 `Aa`、全字匹配 `W`。**F3 / ⇧F3** 跳到下一个 / 上一个匹配。编辑后约一秒，列表会自动刷新。
- **替换 (⌘R)** 增加一个替换字段：替换当前匹配并前进，或**全部替换**。开启正则表达式后，`$1` 之类的模板会插入捕获组。即使有数千个匹配，全部替换也只是一个撤销步骤。
- **在文件中查找 (⇧⌘F)** 搜索一个文件夹（包含子文件夹）。选择文件夹，可选地用 `*.md;*.txt` 之类的掩码加以限制，点按某个结果即可在该行打开该文件。隐藏文件、软件包、二进制文件和超过 20 MB 的文件会被跳过。
- **选择所有匹配 (⌥⌘A)** 将每个匹配变为一个光标——见下文的多光标。

## 7. 书签

**⌘F2** 为当前行添加书签（或移除书签），**F2 / ⌥F2** 跳到下一个 / 上一个书签，底部面板的**书签**标签页会列出所有书签；你可以在那里为书签命名。书签会随着编辑跟随所在行：在其上方插入或删除行会移动它们，删除带书签的行会移除书签，撤销则会恢复它们。书签按文稿存储在 `~/Library/Application Support/HyperEdit/bookmarks/` 下，因此不会在你的文件旁边写入任何内容。

## 8. 列模式与多光标

- **列模式 (⌥C)** — 按住 ⌥ 拖动，或配合 ⇧ 使用方向键，选择一个矩形区域。此后输入和删除会应用于块中的每一行，较短的行用虚拟空格补齐，拷贝 / 粘贴按行进行。状态栏显示 **COL**。再按 ⌥C 关闭。
- **插入序号 (⌥⌘N)** — 用一个数列填充列选区（或每个光标）：选择起始值和步长；数字会补零至相同宽度。
- **多光标** — ⌘-点按添加一个光标，**⌘D** 添加所选文本（或光标处单词）的下一处出现，**⌥⌘A** 选择所有搜索匹配。输入会同时作用于每个光标；Esc 回到单个光标。每次多光标编辑都是一个撤销步骤。

## 9. 行与文本工具

这些工具位于**编辑**功能区标签页和**行**菜单中。它们作用于所选行，未选择时作用于当前行。

| 组 | 工具 |
|---|---|
| 行 | 删除行 ⇧⌘K · 复制行 ⇧⌘D · 上移行 / 下移行 ⌥↑ / ⌥↓ · 合并行 ⇧⌘J · 行倒序 · 给行编号 |
| 大小写 | 大写 · 小写 · 首字母大写 · 大小写互换 |
| 排序 | 升序 · 降序 · 按数字排序（按每行开头的数字）· 删除重复行 |
| 空白 | 删除行尾空白 · 删除首尾空白 · 删除空行 · 制表符 → 空格 · 空格 → 制表符 |

- **计算 (⌃⌘=)** 对所选内容或当前行（若有 `=`，则取最后一个 `=` 之后的部分）求值，并追加 ` ⇒ 结果`：`3+0.5+0.25` 变为 `3+0.5+0.25 ⇒ 3.75`。在已编辑的行上再次运行会替换旧结果。支持：`+ - * / % ^`、括号、`1,234` 和 `1_000` 形式的数字、`sqrt abs round floor ceil min max`、`pi` 和 `e`。无法求值的表达式会在输出面板中报告，文本保持不变。
- **对齐列 (⌃⌘T)** 填充以制表符分隔的列（所选行，或光标周围的制表符行块），使每一列从相同的显示列开始；韩文、中文和日文字符按两个单元格计算。如果每一行都包含 `|`，则该块会被视为 Markdown 表格：单元格在 ` | ` 内补齐，`---` 行会重新绘制，`--:` 列右对齐。
- **切换注释 (⌘/)** 用文件类型的注释符号为行添加或移除注释：代码用 `//`、`#`、`--`……，Markdown 和 HTML 用 `<!-- -->`，CSS 用 `/* */`，纯文本笔记用 `//`。如果每个非空行都已被注释，则全部取消注释，否则全部注释，注释符号对齐到最浅的缩进。空行会被跳过。
- **格式化 JSON (⌃⌘J) / 压缩 JSON** 将所选内容（未选择时为整个文稿）美化输出（2 空格缩进）或压缩为一行。键顺序和数字写法保持不变，非 ASCII 文本不转义，输入可以包含注释和尾随逗号 (JSONC)。遇到语法错误时文本保持不变，输出面板显示 `行:列`，光标跳到该位置。

## 10. 代码片段

输入触发词并按 **Tab** 展开。内置触发词：`todo`、`date`、`time`、`now`、`meeting`、`table`、`link`、`code`。**插入代码片段… (⇧⌘I)** 用一个带过滤框的列表列出全部片段，“开始”标签页中也有“代码片段…”按钮。

片段正文可以包含变量——`${date}`、`${time}`、`${datetime}`、`${selection}`、`${clipboard}`、`${filename}`——以及制表位 `$1` … `$9`、`${1:placeholder}` 和 `$0`。展开后，Tab / ⇧Tab 在制表位之间移动（同一编号出现两次会变成多光标），Esc 或点按结束会话。

**编辑代码片段…**（“编辑”菜单或“开始”标签页）在 HyperEdit 中打开 `~/Library/Application Support/HyperEdit/snippets.json`。每个条目包含 `trigger`、`name` 和 `body`；文件在你存储后会重新读取，因此新触发词立即可用。

## 11. 宏

宏会记录你的输入，并在其他位置重放。

1. **录制宏 (⇧⌘M)** 开始录制；状态栏显示 `● REC`。会记录输入（对于韩文等输入法，记录已上屏的字符）、光标移动、删除、换行、粘贴、文本工具以及查找下一个（F3，连同其查询内容）。鼠标点按、选区更改和多光标编辑不会记录。
2. 再按 **⇧⌘M** 停止录制。
3. **播放宏 (⌥⌘M)** 在光标处重放。**多次播放宏…** 最多重复 10,000 次，并在查找步骤无结果或某一轮未产生更改时自动停止——是一个方便的“对每一行执行此操作”工具。整个运行是一个撤销步骤。

最近的录制只保存在内存中，直到你退出，因此录制时输入的任何敏感内容都不会写入磁盘。**将最近的宏存储为…** 会把它永久添加到**宏**菜单中；已存储的宏位于 `~/Library/Application Support/HyperEdit/macros/macros.json`，**编辑宏文件…** 会在编辑器中打开该文件。

## 12. 代码折叠与滚动条标记

**折叠 (⌥⌘←) / 展开 (⌥⌘→)** 隐藏或显示光标所在的区域；**⌥⇧⌘← / ⌥⇧⌘→** 折叠或展开全部。一个区域是：

- 当前行下方缩进的各行（忽略空行），
- 在 Markdown 中，`#` 标题之下直到下一个同级或更高级标题之间的全部内容（围栏代码块也可折叠），
- 在代码中，以 `{`、`[` 或 `(` 结尾的行直到其闭合括号所在行。

点按行号栏中的箭头，或折叠行之后的 `⋯ N 行` 标签，可用鼠标切换折叠。光标移入折叠行（查找、跳转到行、书签、撤销）会将其展开；↑ / ↓ 会跳过折叠区域。折叠会跟随你的编辑，并在本次会话期间保持。

**滚动条标记** — 编辑器右边缘的细条按其在文件中的相对位置显示搜索匹配（强调色）、书签（警告色）、光标所在行和已折叠的标题行。整个文稿能在屏幕上完整显示时会隐藏。可在**显示 › 滚动条标记**或“布局”标签页的“折叠”组中关闭。

## 13. 拆分编辑器

**⌘\\** 在两个并排的编辑器中显示同一文稿；**显示 › 拆分 › 上下拆分**将它们上下排列，“布局”标签页中也有相同的按钮。两个视图编辑同一份文本并共用一份撤销历史——在一个中输入，在另一个中按 ⌘Z——但各自独立滚动，因此你可以一边阅读文件的某一部分，一边在另一部分书写。命令、状态栏和 Markdown 预览跟随你最后点按的编辑器；**⌥⌘\\** 将焦点移到另一个编辑器。拆分开启时状态栏显示 **SPLIT**；再按 ⌘\\ 关闭。

## 14. 快速追加

**快速追加 (⇧⌘N)** 打开一个小的浮动面板，让你不必离开手头的工作即可添加笔记。输入笔记，按 **⌘↩**，它就会追加到文稿末尾——默认带时间戳标题——立即存储，且可一步撤销。随后面板隐藏，焦点回到你之前所在的应用。**Esc** 关闭面板并保留草稿以备下次使用。

由于该面板不会激活 HyperEdit，它也可以通过**全局快捷键**在任何其他应用中使用：默认为 **⌃⌥N**。在设置中可以将其关闭，或改为 ⌃⌥Space、⌃⇧Space 或 ⌃⌥⌘N，还可以关闭时间戳标题。该快捷键使用系统热键服务，因此不需要辅助功能权限。如果其他应用已占用该组合键，启动时输出面板会提示——请另选一个。

## 15. Markdown 预览与语法着色

- **Markdown 预览 (⇧⌘P)** 拆分窗口，在右侧显示当前文件的渲染视图：标题、列表和任务列表、表格、围栏代码、引用、链接和图像，均以当前主题着色。它跟随编辑器的滚动位置，并在你停止输入后不久重新渲染。链接在浏览器中打开；文件中的原始 HTML 以文本显示，绝不会执行。超过 2 MB 的文件显示提示而非预览。开启时状态栏显示 **MD**。
- **语法着色 (⌃⌘H)** 按文件扩展名选择，并显示在状态栏中。笔记和 Markdown 使用一套轻量规则——URL、日期和时间、标题、`[标题]` 行、列表标记和 `[ ]` / `[x]` 任务框、`#标签`、`key:` 标签、`**粗体**`、`` `代码` `` 以及 `⇒ → ->` 箭头——约 20 种编程语言则有注释、字符串、数字、关键字、函数名和类型名的着色。颜色只绘制在可见行上，因此绝不会更改文件或拖慢输入。跨越多行的结构在闭合之前会保持其颜色：块注释（`/* */`、`<!-- -->`）、多行字符串（Swift 和 Python 的 `"""`、JavaScript 模板字面量、Go 原始字符串、Rust `r#"…"#`）以及 Markdown 围栏代码块——后者按信息字符串中指定的语言着色（```` ```python ````）。输入起始或结束定界符时，下方各行会立即重新着色。
- **用户自定义语法。** 要为 HyperEdit 不认识的语言着色，或修改内置语言，请把 `*.json` 文件放到 `~/Library/Application Support/HyperEdit/grammars/` 中。HyperEdit 首次启动时会创建该文件夹，并附带一个可供复制的 `example.json` 和一份解释每个键的 README——`name`、`extensions` 或 `filenames`、`mode`、`lineComments`、`blockComment`、`strings`、`multilineStrings`、`keywords`、`types`、`constants`、`builtins`、`caseInsensitive`。**文件 › 重新载入语法** 无需重新启动即可应用你的更改；状态栏显示语法名称，切换注释 (⌘/) 使用其注释符号，解析失败的文件会被跳过，并在输出面板中显示消息。

## 16. 主题、字体与中日韩文字

**主题。** 应用自带 22 套配色——5 套浅色、17 套深色。默认跟随系统外观：浅色模式用 **Hyper Light**，深色模式用 **Hyper Dark**。从“布局”标签页、状态栏主题菜单、**显示 › 主题**或 ⌥⌘] / ⌥⌘[ 选择主题即可固定它；**跟随系统外观**位于相同的菜单和设置中。同样的配色也提供给 Zed 编辑器（每个发布版本都附带 `hyperedit-themes.json`）。

**光标与窗口不透明度。** 设置 › **外观** 用于选择光标形状——**竖线**（默认）、**方块**（字符单元格以光标颜色着色，字形仍清晰可读）或**下划线**——以及是否闪烁；多光标和列模式的额外光标使用相同形状。**窗口不透明度**（50–100 %）让整个窗口变为半透明——编辑器、功能区、面板和状态栏都一样——而文字、图标和边框保持不透明；**窗口背景模糊**会加上系统模糊效果。显示 › 窗口不透明度提供 100 / 90 / 80 / 70 % 几档。

**字体。** 已安装 **Fira Code** 时 HyperEdit 使用它，否则使用系统等宽字体。韩文文本用单独的字体绘制——默认是 **D2Coding**（已安装时）——并缩放到一个韩文音节恰好等于两个拉丁字符的宽度，这样以制表符对齐的表格才能保持整齐。连字、行高、两种字体以及韩文缩放都在设置中。中文和日文文本使用系统备选字体，在对齐列中同样按两个单元格计算。

## 17. 存储、快照与编码

- **自动存储**在你停止输入两秒后运行（⌘S 立即存储）。退出、关闭窗口和切换文件时文稿会立即存储，因此这两秒内不会丢失任何内容。每次写入都是原子操作。
- **快照。** 每次会话首次存储前，文件的一份副本会存放在 `~/Library/Application Support/HyperEdit/snapshots` 下（**文件 › 打开快照文件夹**）。每个文件保留最新的 20 份，超过 90 天的会被删除。
- **外部更改。** 如果文件打开期间被其他程序更改，而你没有未存储的编辑，HyperEdit 会重新载入它并保持光标位置不变。如果你有未存储的编辑，外部版本会被保存为快照并显示警告；此时存储会覆盖它。
- **安全。** 绝不会用空缓冲区覆盖原本有内容的文件。如果退出时存储失败，会向快照文件夹写入一份紧急副本，并询问你是否仍要退出。
- **编码。** 文件先按 UTF-8 读取，然后依次尝试 EUC-KR (CP949)、CP1252 和 Latin-1，并以相同编码存储（UTF-8 BOM 会保留）。如果你输入了原编码无法存储的字符，文件会以 UTF-8 存储，状态栏会予以提示。无法用上述任何编码解码的文件不会被打开，而不是遭到损坏。
- **换行符**（UNIX / DOS / MAC）会被检测并保留；快速追加和文本工具使用文件自身的换行符。
- **导出。** **文件 › 导出为 HTML…** 将文稿存储为一个自包含的 HTML 文件——Markdown 按预览的样式渲染，笔记和代码则为带语法着色的代码块——**文件 › 导出为 PDF…** 将同一页面打印为分页的 PDF（美国、加拿大和墨西哥用 Letter，其他地区用 A4；36 pt 页边距；无页眉页脚）。存储面板可选择主题（当前、Hyper Light、Hyper Dark），对笔记和代码还可选择是否显示行号。导出的页面不含脚本，也不从网络载入样式表或字体；图像 URL 按原样保留，因此浏览器（以及 PDF 渲染器）可能会获取远程图像，而把 HTML 存储在 Markdown 文件旁边时相对图像路径即可正常使用。PDF 导出仅支持 2 MB 以内的文件。机密块（第 23 节）导出为 `••••••••`。

## 21. 故障排除

- **语言没有改变。** 新语言在重新启动后生效——使用设置中的**立即重新启动**，或退出后重新打开。如果系统语言是 HyperEdit 不支持的语言，它会显示英语；请在设置中明确选择一种语言。
- **某个文件打不开。** 二进制文件是有意用默认应用打开的。编码不是 UTF-8、EUC-KR、CP1252 或 Latin-1 的文本文件会被拒绝打开而非损坏；请先用其他工具转换。
- **全局快速追加快捷键没有反应。** 可能有其他应用占用了该组合键，或者 ⌃Space / ⌃⌥Space 已被“系统设置 › 键盘”中的输入法切换占用。请在设置中选择 ⌃⌥N 或 ⌃⌥⌘N。启动时输出面板会报告注册结果。
- **表格中的韩文看起来太宽或太窄。** 请安装 D2Coding，或在设置中调整韩文缩放；2:1 宽度修正需要等宽的韩文字体。
- **我误存储了内容。** 打开快照文件夹（**文件 › 打开快照文件夹**）：本次会话首次存储前拍下的副本就在那里，还有检测到外部更改时制作的副本。
- **功能区只显示图标。** 窗口对该标签页来说太窄；请加宽窗口，或将鼠标悬停在图标上查看其标签。

## 22. 已知限制

- 语法着色可跨行跟踪块注释、多行字符串和 Markdown 围栏，但除 Rust 原始字符串外，只支持起止相同的字符串定界符，每种语言只支持一对块注释符号，且用户语法只是单词列表，没有正则表达式规则。Markdown 预览是一个视图，不是编辑器。
- 宏只记录键盘编辑（不记录鼠标、选区或多光标步骤）。计算和对齐列只处理简单算术以及制表符 / 竖线表格。
- 代码片段、宏和用户语法以 JSON 文件形式编辑；没有图形化编辑器。
- 导出只能输出整个文稿，不支持导出选区或多个文件，没有页面或字体选项，也不生成 PDF 目录。
- 机密块只在屏幕上遮盖：文件、自动存储和快照都是纯文本，遮盖条会显示每行的长度，且 VoiceOver 仍会朗读其文本。机密围栏必须从左边距开始（缩进少于四个空格，且不在列表项或引用中）；嵌套在机密块内的围栏代码块需要外层围栏使用四个反引号。应用锁定会隐藏窗口，并对 VoiceOver 隐藏其内容；它不会加密任何内容。
- 块注释不能嵌套，使用经典 Mac（仅 CR）换行符的文件按行着色。在长度超过 20,000 个字符的单个段落中，方块和下划线光标会退回为标准竖线光标。
- 折叠只在本次会话期间保持，不按文件保存；跨过折叠行的鼠标拖动仍会选中隐藏的文本。
- 单行达到一兆字节或更长的文稿打开和移动都很慢；压缩 JSON 在生成这样的文稿前会给出警告。
- 仅支持本地文件；暂无云同步，也没有 iOS 应用。
- 所列十一种语言之外的语言会回退到英语。

## 23. 机密块与应用锁定

**机密块。** 信息字符串以 `secret` 开头的围栏代码块会在编辑器中被遮盖：

````markdown
```secret bank
login: me@example.com
password: hunter2
```
````

两条围栏之间的每一行都绘制为一条带 `••••••••` 的空白条；围栏行保持可见，便于你看到块的位置和用途。该规则在 Markdown 和纯文本文件中相同。将光标移入块中——点按它，使用 ↑ / ↓、跳转到行、查找结果或书签——整个块就会显示出来并可编辑；光标移出后会再次遮盖。改变的只是显示：文本仍在文件中，因此查找、替换、撤销和存储的工作方式与之前完全相同。

- “编辑”菜单中的**显示机密 (⌥⌘S)** 会一次显示所有块；经过**设置 › 机密 › 自动重新遮盖**设定的时间（10 / 30 / 60 秒，默认 30 秒，或永不）后会再次遮盖，并记录在输出面板中。在此期间状态栏显示 `REVEALED`，有 N 个块被遮盖时显示 `•••• N`。**编辑 › 遮盖机密块** 可完全关闭遮盖。
- 机密行在查找结果和在文件中查找的列表中（匹配和行号仍然有效）以及书签预览中显示为 `••••••••`，大纲和时间线会跳过它们，Markdown 预览以及 HTML / PDF 导出中会将其隐去。退出 HyperEdit 时，待执行的剪贴板清除会立即执行。
- **剪贴板自动清除。** 当拷贝或剪切涉及机密行时——包括多光标和列模式的拷贝——剪贴板会在**设置 › 机密 › 拷贝机密内容后清除剪贴板**设定的时间（关闭 / 10 / 30 / 60 秒，默认 30 秒）后被清除，除非你在此期间拷贝了其他内容。**编辑 › 清除剪贴板** 会立即清除；关闭遮盖也会同时关闭自动清除。
- 机密块可以像任何围栏代码块一样折叠 (⌥⌘←)。

> 遮盖不是加密。文件、自动存储和快照都是纯文本，任何拿到文件的人都能读到这些机密。该功能只是在你工作时让它们不出现在屏幕、截屏、查找结果、预览和导出中。

**应用锁定 (Touch ID)。** **HyperEdit › 锁定 HyperEdit (⌃⌘L)**（应用程序菜单中“设置…”下方）会用当前主题的不透明锁定屏幕遮住整个窗口——功能区、边栏、编辑器、面板和状态栏——并关闭已打开的设置窗口、隐藏快速追加面板。锁定期间不显示文稿的任何信息，连文件名也不显示。点按**解锁**（或按 Return 或空格键）即可使用 **Touch ID** 验证；如果 Touch ID 失败或该 Mac 没有 Touch ID，macOS 会改用你的登录密码。锁定还会关闭所有已打开的表单或警告框，重新遮盖已显示的机密，并立即执行待执行的剪贴板清除。取消后 HyperEdit 保持锁定，再点按按钮即可重试。

- **设置 › 应用锁定。** *打开 HyperEdit 时要求 Touch ID 或密码*（默认关闭）会让应用以锁定状态启动：文稿已载入，自动存储照常进行，但在你完成验证之前什么都不显示。*闲置后锁定*（永不 / 1 / 5 / 15 / 30 分钟，默认永不）会在 HyperEdit 中这段时间内没有按键或点按时锁定，与启动选项无关。*Mac 睡眠或屏幕锁定时锁定*（默认开启）在启动选项开启时生效，显示器进入睡眠时同样适用。一行说明文字会告诉你此 Mac 是否可以使用 Touch ID。
- 锁定期间，键盘输入会被拦截，菜单栏无法打开；只有 ⌘Q、⌘H / ⌥⌘H、⌘M、⌘W、⌃⌘F 和程序坞菜单仍然可用。快速追加全局快捷键会显示解锁提示而非面板，完成验证后再打开面板。
- 这是针对屏幕的隐私锁，而非加密：磁盘上的文件保持不变，任何其他应用都能读取。当该 Mac 既没有 Touch ID 也没有登录密码时，无法开启 *要求…* 选项，因此你不会把自己锁在外面。
