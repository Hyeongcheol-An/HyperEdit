# Willkommen bei HyperEdit

HyperEdit ist ein schneller Texteditor für reinen Text, gebaut um eine große Notizdatei, an die du immer weiter anhängst.

## Erste Schritte

- F7 fügt eine Zeitstempel-Überschrift ein: `## 2026-10-31 (Sa.) 09:00`
- ⌘F suchen · ⌘R ersetzen · ⇧⌘F in Dateien suchen
- ⌘F2 setzt oder entfernt ein Lesezeichen, F2 / ⌥F2 springen zum nächsten / vorherigen
- ⌥C Spaltenmodus · ⌘-Klick fügt einen Cursor hinzu · ⌘D wählt den nächsten Treffer aus
- ⌘/ kommentiert · ⌃⌘J formatiert JSON · tippe `todo` und drücke Tab für ein Snippet
- ⇧⌘N öffnet die Schnelleingabe – oder ⌃⌥N aus jeder App – um eine Notiz ans Ende dieser Datei anzuhängen
- ⌘1 Seitenleiste (Dateien / Gliederung / Zeitleiste) · ⌘2 unteres Panel (Suchergebnisse / Lesezeichen / Ausgabe)
- Tab „Layout“ → Theme: 22 Themes; standardmäßig folgt die App der Hell/Dunkel-Einstellung des Systems
- ⌘, öffnet die Einstellungen – Schriften, Theme, Sprache der Oberfläche und der Kurzbefehl für die Schnelleingabe
- ⌘O öffnet jede Textdatei. Diese Datei liegt unter ~/Documents/HyperEdit/notes.md

Änderungen werden automatisch zwei Sekunden nach der letzten Eingabe gesichert, und vor dem ersten Sichern
jeder Sitzung wird ein Schnappschuss der vorherigen Version aufbewahrt.

Lösche diesen Text und fang an zu schreiben.
