# Bem-vindo ao HyperEdit

O HyperEdit é um editor de texto simples e rápido, construído em torno de um único arquivo grande de notas ao qual você continua acrescentando coisas.

## Primeiros passos

- F7 insere um cabeçalho de data/hora: `## 2026-10-31 (sáb) 09:00`
- ⌘F buscar · ⌘R substituir · ⇧⌘F buscar em arquivos
- ⌘F2 adiciona ou remove um marcador; F2 / ⌥F2 vão para o seguinte / anterior
- ⌥C modo coluna · ⌘-clique adiciona um cursor · ⌘D seleciona a próxima ocorrência
- ⌘/ comenta ou descomenta · ⌃⌘J formata JSON · digite `todo` e pressione Tab para inserir um snippet
- ⇧⌘N abre a Adição Rápida — ou ⌃⌥N a partir de qualquer app — para adicionar uma nota ao fim deste arquivo
- ⌘1 barra lateral (Arquivos / Estrutura / Linha do Tempo) · ⌘2 painel inferior (Resultados da Busca / Marcadores / Saída)
- Aba Layout → Tema: 22 temas; por padrão o app segue o modo claro/escuro do sistema
- ⌘, abre os Ajustes — fontes, tema, idioma da interface e o atalho da Adição Rápida
- ⌘O abre qualquer arquivo de texto. Este arquivo fica em ~/Documents/HyperEdit/notes.md

As alterações são salvas automaticamente dois segundos depois que você para de digitar, e um snapshot da versão
anterior é guardado antes do primeiro salvamento de cada sessão.

Apague este texto e comece a escrever.
