# HyperEdit へようこそ

HyperEdit は、追記し続ける 1 つの大きなメモファイルを中心に設計された、高速なプレーンテキストエディタです。

## はじめに

- F7 でタイムスタンプ見出しを挿入: `## 2026-10-31 (土) 09:00`
- ⌘F 検索 · ⌘R 置換 · ⇧⌘F ファイルから検索
- ⌘F2 でブックマークを切り替え、F2 / ⌥F2 で次 / 前のブックマークへ移動
- ⌥C 列モード · ⌘クリックでカーソルを追加 · ⌘D で次の一致を選択
- ⌘/ でコメント切替 · ⌃⌘J で JSON を整形 · `todo` と入力して Tab でスニペットを展開
- ⇧⌘N でクイック追加 — 他のアプリからは ⌃⌥N — このファイルの末尾にメモを追加
- ⌘1 サイドバー (ファイル / アウトライン / タイムライン) · ⌘2 下部パネル (検索結果 / ブックマーク / 出力)
- レイアウトタブ → テーマ: 22 のテーマ。デフォルトではシステムのライト/ダーク設定に従います
- ⌘, で設定を開く — フォント、テーマ、インターフェイスの言語、クイック追加のショートカット
- ⌘O で任意のテキストファイルを開く。このファイルは ~/Documents/HyperEdit/notes.md にあります

変更は入力を止めてから 2 秒後に自動的に保存され、各セッションの最初の保存の前に
以前のバージョンのスナップショットが保持されます。
