# Te damos la bienvenida a HyperEdit

HyperEdit es un editor de texto sin formato rápido, construido en torno a un único archivo grande de notas al que sigues añadiendo cosas.

## Primeros pasos

- F7 inserta un encabezado con marca de tiempo: `## 2026-10-31 (sáb) 09:00`
- ⌘F buscar · ⌘R reemplazar · ⇧⌘F buscar en archivos
- ⌘F2 añade o quita un marcador, F2 / ⌥F2 saltan al siguiente / anterior
- ⌥C modo columna · ⌘-clic añade un cursor · ⌘D selecciona la siguiente coincidencia
- ⌘/ comenta o descomenta · ⌃⌘J formatea JSON · escribe `todo` y pulsa Tab para un fragmento
- ⇧⌘N abre Apunte rápido — o ⌃⌥N desde cualquier app — para añadir una nota al final de este archivo
- ⌘1 barra lateral (Archivos / Esquema / Cronología) · ⌘2 panel inferior (Resultados de búsqueda / Marcadores / Salida)
- Pestaña Disposición → Tema: 22 temas; de forma predeterminada la app sigue el ajuste claro/oscuro del sistema
- ⌘, abre Ajustes: tipos de letra, tema, idioma de la interfaz y el atajo de Apunte rápido
- ⌘O abre cualquier archivo de texto. Este archivo está en ~/Documents/HyperEdit/notes.md

Los cambios se guardan automáticamente dos segundos después de que dejes de escribir, y antes del primer guardado
de cada sesión se conserva una instantánea de la versión anterior.

Borra este texto y empieza a escribir.
