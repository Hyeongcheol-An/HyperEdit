# Welcome to HyperEdit

HyperEdit is a fast plain-text editor built around one big notes file that you keep appending to.

## Getting started

- F7 inserts a timestamp heading: `## 2026-10-31 (Sat) 09:00`
- ⌘F find · ⌘R replace · ⇧⌘F find in files
- ⌘F2 toggles a bookmark, F2 / ⌥F2 jump to the next / previous one
- ⌥C column mode · ⌘-click adds a caret · ⌘D selects the next match
- ⌘/ toggles comments · ⌃⌘J formats JSON · type `todo` and press Tab for a snippet
- ⇧⌘N opens Quick Append — or ⌃⌥N from any app — to add a note to the end of this file
- ⌘1 sidebar (Files / Outline / Timeline) · ⌘2 bottom panel (Find Results / Bookmarks / Output)
- Layout tab → Theme: 22 themes; by default the app follows the system light/dark setting
- ⌘, opens Settings — fonts, theme, the interface language and the Quick Append shortcut
- ⌘O opens any text file. This file lives at ~/Documents/HyperEdit/notes.md

Changes are saved automatically two seconds after you stop typing, and a snapshot of the previous
version is kept before the first save of each session.

Delete this text and start writing.
