# HyperEdit에 오신 것을 환영합니다

HyperEdit는 계속 끝에 덧붙여 쓰는 큰 메모 파일 하나를 위한 빠른 일반 텍스트 에디터입니다.

## 시작하기

- F7은 타임스탬프 헤딩을 삽입합니다: `## 2026-10-31 (토) 09:00`
- ⌘F 찾기 · ⌘R 바꾸기 · ⇧⌘F 파일에서 찾기
- ⌘F2로 북마크를 토글하고, F2 / ⌥F2로 다음 / 이전 북마크로 이동합니다
- ⌥C 열 모드 · ⌘-클릭으로 커서 추가 · ⌘D로 다음 매치 선택
- ⌘/ 주석 토글 · ⌃⌘J JSON 정리 · `todo`를 치고 Tab을 누르면 스니펫
- ⇧⌘N으로 빠른 추가를 열어 — 다른 앱에서는 ⌃⌥N — 이 파일 끝에 메모를 덧붙입니다
- ⌘1 사이드바 (파일 / 아웃라인 / 타임라인) · ⌘2 하단 패널 (찾기 결과 / 북마크 / 출력)
- 레이아웃 탭 → 테마: 22개 테마, 기본으로는 시스템의 라이트/다크 설정을 따릅니다
- ⌘,로 설정을 엽니다 — 폰트, 테마, 인터페이스 언어, 빠른 추가 단축키
- ⌘O로 아무 텍스트 파일이나 엽니다. 이 파일은 ~/Documents/HyperEdit/notes.md에 있습니다

입력을 멈추면 2초 뒤 자동으로 저장되고, 세션마다 첫 저장 전에 이전 버전의
스냅샷을 보관합니다.

이 글을 지우고 쓰기 시작하세요.
