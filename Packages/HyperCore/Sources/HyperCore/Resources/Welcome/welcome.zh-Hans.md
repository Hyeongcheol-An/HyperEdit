# 欢迎使用 HyperEdit

HyperEdit 是一款快速的纯文本编辑器，围绕一个不断追加内容的大笔记文件而设计。

## 快速上手

- F7 插入时间戳标题：`## 2026-10-31 (周六) 09:00`
- ⌘F 查找 · ⌘R 替换 · ⇧⌘F 在文件中查找
- ⌘F2 切换书签，F2 / ⌥F2 跳到下一个 / 上一个书签
- ⌥C 列模式 · ⌘-点按添加光标 · ⌘D 选择下一匹配
- ⌘/ 切换注释 · ⌃⌘J 格式化 JSON · 输入 `todo` 后按 Tab 展开代码片段
- ⇧⌘N 打开快速追加 — 在任何应用中也可按 ⌃⌥N — 把笔记添加到本文件末尾
- ⌘1 边栏（文件 / 大纲 / 时间线）· ⌘2 底部面板（查找结果 / 书签 / 输出）
- “布局”标签页 → 主题：22 款主题；默认跟随系统的浅色/深色设置
- ⌘, 打开设置 — 字体、主题、界面语言和快速追加快捷键
- ⌘O 可打开任意文本文件。本文件位于 ~/Documents/HyperEdit/notes.md

停止输入两秒后更改会自动存储；每次会话首次存储前，会保留一份先前版本的快照。
